家族の中で、AIを使う人が増えてきました。子どもが宿題の調べものに使う、親が仕事や家事の相談に使う、祖父母が音声で質問してみる。使う場面が広がるほど、「どこまでならよいのか」を家族で決めておきたくなります。

けれども、親が一方的にルールを決めると、子どもは「やらされている」と感じて、こっそり使うようになることがあります。ルールは、**一緒に作って、一緒に見直す**ほうが、長続きしやすくなります。

この記事では、家族でAIを使うときのルールを、**どんな手順で作るか**に焦点を当てて整理します。ルールに入れる中身(何を決めておくとよいか)の整理は[子どもがAIを使うとき保護者が知っておきたいこと](/kodomo-ai-riyou-hogosha/)で扱っているので、ここでは重なりを避け、話し合いの進め方、ルールの書き方、守れなかったときの対応、見直しの方法を中心に説明します。

## ルールは「禁止リスト」ではなく「家族の約束」にする

ルールを作る前に、考え方を整えておきます。

ルールというと、「〜してはいけない」の禁止リストを想像しがちです。しかし、禁止ばかりが並ぶと、読む側は窮屈に感じます。しかも、禁止リストは、書かれていない場面で役に立ちません。新しいAIや新しい使い方が出てくるたびに、「これは禁止されていない」という抜け道ができてしまいます。

そこで、ルールを**家族の約束**として作る考え方があります。禁止ではなく、「大切にしたいこと」を中心に置きます。

| 禁止リストの形 | 約束の形 |
|---|---|
| 個人情報を入力してはいけない | 自分や友だちのことを守るため、名前や住所は入力しない |
| 宿題をAIにやらせてはいけない | 自分の力をつけるため、答えは自分で書く |
| 夜遅く使ってはいけない | 体を休めるため、寝る前は画面を閉じる |
| 知らないサービスを使ってはいけない | 安全のため、新しいサービスは家族に見せてから使う |

右の列は、理由がセットになっています。理由があれば、ルールに書かれていない場面でも、「この約束の目的は何だったか」から判断できます。

約束の形にするときの、基本の考え方は次のとおりです。

- **理由を書く**: なぜその約束が必要かを、一緒に書く
- **短く、少なくする**: 覚えきれない数のルールは、守られない
- **大人も守る**: 家族全員が対象であることを示す
- **変えられると伝える**: 状況が変われば、見直すことを最初に決めておく

特に三つ目の「大人も守る」は、重要です。親が仕事の資料作りでAIを使っているのに、子どもにだけ制限をかけると、納得は得にくくなります。大人も、入力してはいけない情報、確認の習慣などを一緒に守る姿勢を示すと、ルールが「家族のもの」になります。

## 話し合いの進め方｜ルールを作る前の三つのステップ

ルールを作る話し合いは、いきなり「ルールを決めよう」と始めるより、段階を踏むとうまくいきやすくなります。

**ステップ1｜まず、今の使い方を聞く**

最初は、ルールの話をしません。家族が、AIを**どう使っているか、使ってみたいか**を聞きます。

- どんなときに使っているか
- 使ってみて、よかったことは何か
- 困ったことや、不安になったことはあるか
- これから使ってみたいことは何か

このとき、**評価や注意をしない**ことがコツです。「それはだめでしょう」と言われると、話してくれなくなります。まずは、聞くことに徹します。

**ステップ2｜一緒に、AIを使ってみる**

話を聞くだけでなく、実際に一緒に使ってみるのも効果的です。たとえば、家族で一つの質問を考えて、AIに聞いてみます。

- 答えがもっともらしく見えても、間違っていることがある
- 同じ質問でも、聞き方で答えが変わる
- 個人的なことを入力するときは、注意が必要

こうしたことを、実際に目で見ると、言葉で説明するより伝わります。ChatGPTのような対話型のAIは、家族で並んで画面を見ながら使うことができます。使える機能や年齢の条件などは、サービスによって異なります。利用前に、公式サイトで確認してください。

**ステップ3｜心配なことと、大切にしたいことを出し合う**

使い方を知ったうえで、ルールに入れたいことを出し合います。親だけでなく、子どもの意見も聞きます。

| 立場 | 出てきやすい意見 |
|---|---|
| 保護者 | 個人情報が心配、宿題を任せきりにならないか、使いすぎないか |
| 子ども | 調べものを早く済ませたい、友だちも使っている、疑われたくない |
| 祖父母など | 難しそうで不安、どんなことに気をつければよいか知りたい |

意見が違うことは、悪いことではありません。違いを出し合うことで、お互いの心配や希望が分かります。この段階では、結論を急がず、メモに書き出すだけで十分です。

## ルールシートを作る｜書き方の例

話し合いが済んだら、決まったことを**一枚の紙(ルールシート)**にまとめます。口頭の約束だけでは、あとで「言った・言わない」になりやすいためです。

ルールシートに入れる項目は、次のような形が使いやすいです。

| 項目 | 内容の例 |
|---|---|
| 約束の名前 | 〇〇家のAIの約束 |
| 使う人 | 家族全員 |
| 使ってよいとき | 調べものの手がかり、アイデア出し、言葉の意味の確認 |
| 使う前に確認すること | 学校や職場のルールに合っているか |
| 入力しないこと | 名前、住所、電話番号、学校名、友だちや家族の情報 |
| 答えを使うとき | 内容を別の資料で確かめる。自分の言葉で書き直す |
| 困ったとき | すぐに家族に見せる。怒らないことを約束する |
| 見直す日 | 〇か月後の〇日 |
| 署名欄 | 家族全員の名前 |

特に「困ったとき」の項目は大切です。子どもが困ったとき、親に相談しやすい雰囲気を、ルールとして明文化します。「見せたら怒られる」と思うと、隠してしまうからです。

実際のルールシートのひな形を、次に示します。かっこの中を、家族の事情に合わせて置きかえてください。

```text
(  )家のAIの約束

1. AIは、(調べものの手がかり・アイデア出し)に使います。
   理由: (自分の力をつけるために、答えを丸写しにしないため)

2. 次のことは、AIに入力しません。
   (名前、住所、電話番号、学校名、友だちや家族の情報)
   理由: (自分と周りの人を守るため)

3. AIの答えは、(別の本やサイトで確かめてから)使います。
   理由: (AIはまちがうことがあるため)

4. 困ったことや、変だと思ったことは、すぐに家族に伝えます。
   家族は、(責めずに)一緒に考えます。

5. (宿題や提出物)での使い方は、先生のルールを優先します。

6. この約束は、(  )か月後に、家族みんなで見直します。

名前: (      )(      )(      )(      )
```

ルールの数は、五つか六つ程度に収めると覚えやすくなります。冷蔵庫など、家族の目につく場所に貼っておくと、思い出すきっかけになります。

## 守れなかったとき、どうするか

ルールを作っても、守れない場面は出てきます。そのとき、どう対応するかを、**あらかじめ決めておく**ことが、ルールを長続きさせるコツです。

守れなかったときの、基本の考え方は次のとおりです。

- **まず、事実を聞く**: 何があったのか、どう使ったのか
- **責める前に、理由を聞く**: なぜそうしたのか。ルールが現実に合っていなかったのかもしれない
- **隠さず話してくれたことを、認める**: 話したことで怒られると、次から隠す
- **ルールの側を見直す**: 守れないルールは、ルールの方に無理がある可能性がある

対応の流れを、表にまとめます。

| 場面 | 避けたい対応 | おすすめの対応 |
|---|---|---|
| ルール違反に気づいた | 頭ごなしに叱る | 状況を聞く。どう感じたか尋ねる |
| 本人から打ち明けてきた | 違反を理由に罰する | 話してくれたことを認め、一緒に対策を考える |
| 何度も同じ違反が起きる | 罰を重くする | ルールが現実に合っているか見直す |
| 大人が守れなかった | 黙ってごまかす | 大人も認めて、謝る |

罰を決めておく場合も、「AIを使わせない」のような重い罰は、逆効果になることがあります。隠して使う原因になるためです。罰より、「もう一度話し合う」「確認の頻度を増やす」など、**話し合いに戻る形**のほうが、長い目で見るとうまくいきやすくなります。

そして、深刻な問題(個人情報を入力してしまった、不審な相手とやり取りしてしまった、など)が起きたときは、すぐに保護者が対応できるよう、手順を決めておきます。個人情報の扱いについては[AIと個人情報|入力していいこと・ダメなこと](/ai-to-privacy-kojinjouhou/)で考え方を整理しています。サービス側の対応方法は、公式サイトの案内で確認してください。

## ルールを見直す｜続けるための仕組み

AIは変化が速く、サービスの内容も変わります。家族の状況も変わります。子どもの成長、学校の方針、仕事の内容。一度決めたルールを、ずっと同じまま使い続けるのは、現実的ではありません。

**見直しのタイミング**

見直しは、次のようなタイミングで行います。

- あらかじめ決めた日(数か月に一度など)
- 学年が変わるとき、進学のとき
- 新しいサービスを使い始めるとき
- ルールを守れない場面が続いたとき
- 学校から、AIに関する新しい案内があったとき

**見直しの進め方**

見直しの話し合いでは、次の三つを順番に聞くと、スムーズです。

1. 続けたいルールは何か(うまくいっていること)
2. 守りにくいルールは何か(困っていること)
3. 追加したいルールは何か(新しく心配になったこと)

守りにくいルールは、**なぜ守りにくいのか**を聞きます。理由が分かれば、ルールの書き方を変えたり、例外を設けたりして、現実に合わせられます。

また、見直しの場は、**ルールを管理する場ではなく、AIについて話し合う場**にするとよいでしょう。最近見たAIのニュース、面白かった使い方、不安に思ったこと。そんな話を気軽にできる関係が、いちばんの安心材料です。AIの利用規約の読み方は[AIの利用規約はどこを読めばいい?](/ai-riyoukiyaku-yomikata/)も参考になります。

最後に、ルール作りのチェックリストをまとめます。

- ルールの目的を、禁止ではなく「大切にしたいこと」で説明できる
- 作る前に、家族がどう使っているかを、評価せずに聞いた
- 一緒にAIを使ってみる機会を作った
- 子どもの意見も、ルールに反映した
- ルールを一枚の紙にまとめた
- ルールの数を絞り、理由もあわせて書いた
- 大人も同じルールを守る
- 困ったときに、責めずに相談できる約束がある
- 見直す日を決めた
- 年齢制限や利用規約は、各サービスの公式サイトで確認した

## まとめ

家族でAIを使うときのルールづくりを、振り返ります。

- ルールは、禁止リストではなく、理由つきの「家族の約束」にする
- 作る前に、今の使い方を聞き、一緒にAIを使ってみる
- 決まったことは、短く、少なく、一枚の紙にまとめる
- 大人も同じ約束を守る
- 守れなかったときは、責めずに事実と理由を聞き、ルールの側も見直す
- 定期的に見直し、AIについて話し合える関係を保つ

完璧なルールを最初から作ろうとしなくて構いません。まずは小さな約束を一つ決めて、使いながら育てていきましょう。ルールを作る過程で、家族がAIについて話し合うこと自体が、家庭でのAIリテラシーを育てる一歩になります。

ルールシートが貼ってあっても、日々の会話がなければ、少しずつ忘れられていきます。夕食のときに「最近AIで何か面白いことあった？」と聞いてみる。それだけで、ルールが生きた約束として残りやすくなります。

なお、年齢の制限や保護者向けの設定は、サービスごとに異なります。ルールを決める前に、使うサービスの公式サイトで、最新の案内を確認してください。
