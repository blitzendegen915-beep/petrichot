会議が長引く原因は、話し合う内容そのものよりも、準備の不足にあることがあります。何を決める会議なのかが参加者の間でそろっていないと、情報共有で終わったり、話が横にそれたりしやすくなります。

会議の記録をAIでまとめる方法は[AI議事録・メモ術で会議を効率化](/ai-gijiroku-memo-jutsu/)で紹介しています。この記事は、その手前にあたる「会議の前」を扱います。AIを使って事前アジェンダを作り、参加者に共有するところまでの手順を説明します。

AIは、散らばったメモを整理して、順番を考えるのが得意です。一方で、その会議で本当に決めるべきことが何かは、AIには分かりません。そこは人が決めます。この線引きを意識しながら進めてください。

## アジェンダに入れるべきものを整理する

アジェンダというと、議題を並べた一覧を想像しがちです。しかし、議題の名前だけが並んでいても、参加者は何を準備すればよいか分かりません。事前に共有するアジェンダには、次の項目が入っていると役に立ちます。

| 項目 | 内容 | 書き方の例 |
|---|---|---|
| 会議の目的 | この会議で何を達成したいか | 「来月の担当割りを決める」 |
| 決めたいこと | 会議の終わりまでに結論を出す事柄 | 「A案とB案のどちらで進めるか」 |
| 共有だけすること | 結論は不要で、知っておいてもらう事柄 | 「先週の進捗の報告」 |
| 議題ごとの時間 | 話し合いに使う時間の目安 | 「議題1は【　】分」 |
| 話す人 | 議題を説明する担当 | 「議題2は【担当者名】」 |
| 事前に読む資料 | 参加者が前もって見ておくもの | 「添付の比較表」 |
| 参加者への依頼 | 準備してきてほしいこと | 「意見があれば事前に一言」 |

とくに大事なのは、「決めたいこと」と「共有だけすること」を分けることです。両方が混ざっていると、共有で十分な話題に議論の時間を使ってしまいます。逆に、決めるべきことの時間が足りなくなります。

議題を並べる前に、まず自分に問いかけてください。「この会議が終わったとき、何が決まっていれば成功か」。答えが一言で出ないなら、会議を開く前に目的を絞り込む必要があるかもしれません。会議の代わりに、文章での共有で済むことも多くあります。

## 材料を集めてAIに渡す

アジェンダの材料は、すでに手元にあります。前回の議事録、メールやチャットでの相談、担当者から出ている課題などです。これらを集めて、箇条書きにします。

材料を渡す前に、次のことを確認してください。

- 個人名、顧客名、金額、人事に関わる内容を、そのまま入力して問題ないか
- 社外秘の資料を、使うAIサービスに入力してよい決まりか
- 必要なら、伏せ字や「A社」「担当者X」のような置き換えをしたか

AIサービスに入力した内容がどう扱われるかは、サービスや契約ごとに違います。社内のルールがあれば、それに従ってください。判断に迷うときは、固有名詞を使わなくても成り立つ材料にしておくと安全です。

材料の整理では、AIに最初から並べ替えさせるのではなく、人が先に「今回の会議で扱いたいこと」を三つ程度に絞っておくと、うまくいきます。材料を全部入れて「アジェンダにして」と頼むと、すべてを均等に扱った、ぼんやりしたアジェンダが返ってくるためです。

材料が長いときは、前回の議事録のうち今回に関係する部分だけを抜き出して渡します。関係の薄い部分まで入れると、AIがそちらに引っ張られ、アジェンダが散らかります。前回の宿題がまだ残っているなら、「未完了の項目」として別に書き添えておくと、今回の議題に入れるかどうかを判断しやすくなります。

もし議題の候補が多すぎて絞れないなら、AIに「議題を、決めること、共有だけでよいこと、会議でなくてもよいことに分類してください」と頼めます。分類の結果は参考にして、最終的な判断は自分で行います。

## 依頼文の例：決めることを軸にアジェンダを作る

材料がそろったら、次の依頼文を使います。ClaudeやChatGPTのような対話型のAIは、例として挙げられる選択肢です。社内で使ってよいサービスが決まっている場合は、そちらを使ってください。

```
会議の事前アジェンダを作ってください。

会議の目的: 【来月のイベント準備の担当割りを決める】
参加者: 【企画担当2名、営業担当1名、進行役(私)】
会議の長さ: 【60分】
前回までの状況:
【前回の議事録の要点を貼る】

今回扱いたいこと:
【1. 当日の役割分担 / 2. 予算の使い道の確認 / 3. 告知の進め方】

出力の条件:
- 議題ごとに「決めること」か「共有のみ」かを明記する
- 議題ごとに、時間配分の案を出す(合計が会議の長さに収まるように)
- 事前に読んでほしい資料と、準備してきてほしいことを分けて書く
- 材料に書かれていない事実は補わず、不明な点は最後に質問としてまとめる
```

この依頼文でも、「補わない」と「質問としてまとめる」を入れています。AIは、材料にない人名や数字を、それらしく埋めてしまうことがあるためです。

Claudeは、長い文章を渡して整理させる用途で例に挙げられる製品のひとつです。使える機能や条件は変わることがあるため、公式サイトで確認してください。

出力を受け取ったら、まず「質問」の部分を見てください。AIが材料から読み取れなかった点が並んでいるので、答えられるものは答えて、「質問への回答を反映して作り直してください」と続けます。この往復を一度か二度挟むだけで、アジェンダの具体性が上がります。

出力されたアジェンダは、あくまで案です。時間配分は特に見直してください。AIは各議題に均等に近い時間を割り当てる傾向があります。実際には、結論を出すべき議題に時間を多く割き、共有だけの議題は短くするほうが、会議は終わりやすくなります。

## 時間配分と順番を人の目で見直す

AIが出したアジェンダを、そのまま使う前に、次の観点で見直します。

1. **決めることを前半に置いているか**: 会議の終盤は時間が押しやすく、大事な議題が駆け足になる。重要な決定は、集中力のある前半に置く
2. **共有のみの議題は短くなっているか**: 報告は資料を事前に読んでもらい、会議では質問だけ受ける形にできないか
3. **依存関係に問題はないか**: ある議題の結論が、別の議題の前提になっているなら、順番を入れ替える
4. **余白があるか**: 時間をぎっしり詰めると、少し脱線しただけで崩れる。最後に余白を取っておく
5. **参加者全員が必要な議題か**: 一部の人にしか関係ない議題は、会議の外で済ませられないか

次の表は、議題の種類ごとの時間の考え方の例です。数字ではなく、比率の考え方で示します。

| 議題の種類 | 時間の取り方 | 進め方の工夫 |
|---|---|---|
| 結論を出す議題 | 多めに取る | 案を事前に配り、会議では比較と決定に集中する |
| 意見を集める議題 | 中くらい | 事前に意見を募り、会議では論点だけ取り上げる |
| 報告のみの議題 | 短く | 資料を事前に共有し、質問だけ受ける |
| 次回以降に持ち越す議題 | 取らない | 担当と期日だけ決める |

時間配分は、AIに「議題2を長くして、議題3を短くしてください」と具体的に頼めば、作り直してくれます。ただし、議題ごとの重さを知っているのは、参加者を知っている人だけです。最終的な配分は、人が決めてください。

## 事前共有の文面を整え、会議後にも活かす

アジェンダは、共有して初めて意味を持ちます。会議の直前に渡されても、参加者は準備ができません。共有のタイミングは、準備に時間が必要な内容なら早めに、そうでなければ前日までに届くようにするのが目安です。

共有の文面も、AIに整えてもらえます。次のように頼みます。

```
次のアジェンダを、会議の参加者に送る案内文にしてください。
- 冒頭で、会議の目的と、終わるまでに決めることを一文で伝える
- 事前に読んでほしい資料と、準備してきてほしいことを箇条書きにする
- 参加できない場合の連絡方法を一文添える
- 丁寧だが、長くしない

【アジェンダ】…
```

出力された案内文は、送る前に次を確認します。

- 日時、場所(またはオンラインの案内)、参加者の名前に間違いはないか
- 添付した資料は、正しいファイルか。最新の版か
- 準備を頼む内容は、参加者の負担として無理がないか
- 社外の人が含まれる場合、社内向けの内容が入っていないか

AIが作った文面は、日時などを材料から取り違えることがあります。送信前には、元の情報と見比べてください。

アジェンダは、会議が終わると役目を終えるわけではありません。会議の記録を取るときの骨組みとして使うと、議事録が整いやすくなります。議題ごとに「決まったこと」「持ち越したこと」「次の担当」を書き込む形にしておくと、会議後に読み返したとき、何が進んだのか一目で分かります。

録音や文字起こしを使う場合は、参加者への事前の確認が必要です。進め方は[会議をAIで録音する前に確認しておきたいこと](/kaigi-rokuon-mae-kakunin/)で整理しています。

また、依頼文で出力の形をそろえておくと、毎回同じ形のアジェンダが作れます。形をそろえる考え方は、[AIの回答をいつも同じ形式で受け取るコツ](/ai-shutsuryoku-format-kotei/)が参考になります。うまくいったアジェンダの形はテンプレートとして保存し、会議に合わせて項目を足したり削ったりして、自分たちの形に育ててください。

## まとめ

AIでアジェンダを作るときは、人が会議の目的と決めることを先に決め、AIには整理と文面づくりを任せます。

- アジェンダには、目的、決めたいこと、共有だけのこと、時間、担当、事前資料を入れる
- 材料を渡す前に、個人名や機密を伏せ、社内のルールを確認する
- 依頼文で「決めること」と「共有のみ」の区別を指定し、補わせない
- 時間配分は、決めることを前半に置き、余白を残す形に人が見直す
- 共有の文面は、日時や資料を元の情報と見比べてから送る

会議は、準備の質で終わり方が変わります。AIは準備の手間を減らしてくれますが、会議の目的を決めるのは人の役割です。目的が決まっていれば、アジェンダの作り直しも短い指示で済みます。会議が終わったあとに、アジェンダと実際の進み方を見比べ、時間が足りなかった議題を次回の配分に反映すると、少しずつ精度が上がります。次の会議の前に、まず「終わったとき何が決まっていれば成功か」を一文で書き出し、それをAIに渡すところから始めてみてください。
