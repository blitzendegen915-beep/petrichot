文章を整えてくれるAIツールは、専用の校正ツールから、対話型のAIに「校正して」と頼む方法まで、さまざまな形があります。選択肢が多いぶん、何を基準に選べばよいかが分かりにくくなります。

この記事では、どのツールが良いかは決めません。代わりに、自分の用途に合う校正ツールを選ぶために確認したい観点を、順番に整理します。最後に、選ぶときに使えるチェックリストもまとめました。

校正したい文章の直し方そのものを知りたい場合は、[AIが書いた文章の直し方](/ai-bunshou-teisei/)が参考になります。ここで扱うのは、道具を選ぶ段階の話です。製品ごとの機能や料金は変わりやすいので、具体的な内容は公式サイトで確認してください。

## まず「校正」で何を任せたいかを分ける

「校正」という言葉は、実際にはいくつかの作業をまとめて指しています。ツールを選ぶ前に、自分が何を任せたいのかを分けておくと、必要な機能が見えてきます。

| 作業 | 内容 | 例 |
|---|---|---|
| 誤字・脱字の確認 | 文字の間違いを見つける | 変換ミス、抜けた助詞 |
| 表記ゆれの統一 | 同じ言葉の書き方をそろえる | 「ください」と「下さい」 |
| 文法・係り受けの確認 | 文の組み立ての不自然さを見つける | 主語と述語のずれ |
| 文体・トーンの調整 | 読み手に合わせた言い方にする | 丁寧さ、硬さ |
| 内容の確認(校閲) | 事実や数字が正しいか確かめる | 日付、固有名詞 |

AIツールが得意にしやすいのは、上の3つ、つまり誤字、表記、文法の確認です。一方で、いちばん下の事実確認は、AIに任せきりにできません。AIはもっともらしい誤りを出すことがあるため、日付、金額、固有名詞は、人が元の資料に当たって確認します。

自分の作業に当てはめて、「毎回必要なもの」と「たまに必要なもの」に分けてみてください。毎回必要な作業を確実にこなせるツールが、選ぶ候補になります。たとえばメールの文面なら、誤字と丁寧さの確認が中心です。レポートや記事なら、表記の統一と文のつながりの確認が重くなります。

## 対象にしたい文書の種類と長さを確かめる

次に確認したいのは、どんな文書を、どのくらいの長さで扱うかです。ツールによって、得意な場面や向く使い方が違うからです。

確認する項目は次のとおりです。

- 短いメールやチャットの文面か、長いレポートや記事か
- 文書の形式は何か(テキスト、文書ファイル、ウェブ上の入力欄など)
- 敬語やビジネス文書の言い回しを直したいのか
- 専門用語の多い文章か
- 日本語だけか、他の言語も扱うか

短い文面を頻繁に直すなら、ブラウザやメールの入力欄でそのまま使える形が便利です。長い文書を扱うなら、ファイルを読み込めるか、長さの制限がどうなっているかが重要になります。これらは、ツールごとに異なる仕様です。公式サイトの説明を読んで、自分の文書で使える範囲かを確かめます。

専門用語の多い文章では、AIが用語を「普通の言葉」に直してしまうことがあります。この点は次の節で扱う「直し方の見せ方」と合わせて、自分の文章で試して確かめてください。

試すときは、実際に書いた文章のうち、普段よく間違える箇所が含まれているものを選びます。きれいに書けた文章で試しても、差が見えないからです。

## 直し方の見せ方で、使い勝手が大きく変わる

校正ツールを使い込むと、最も差が出るのが「直し方の見せ方」です。同じ指摘でも、見せ方によって手間が大きく変わります。

確認したいポイントは次のとおりです。

- 直した箇所が分かるか(変更履歴のように、前後を比べられるか)
- 直す理由が説明されるか
- 提案を一つずつ採用・却下できるか
- 全体を一度に書き換える形ではないか
- 元の文章に戻せるか

直した箇所が見えない形のツールは、気づかないうちに意味が変わるリスクがあります。たとえば「この日までに」を「この日ごろ」と書き換えられても、後から読み返さない限り分かりません。校正の目的は文章を良くすることであり、内容を変えることではないので、変更が見える形のほうが安心です。

対話型のAIに校正を頼む場合は、依頼文で見せ方を指定できます。例として、ChatGPTやClaudeのような対話型AIには、次のように頼む方法があります。

```
次の文章を校正してください。
・直した箇所は、元の文と直した文を並べて示してください
・直した理由を一言ずつ添えてください
・意味や数字、固有名詞は変えないでください
・迷う箇所は直さずに、質問として挙げてください
---
(ここに文章を貼る)
```

このように条件を明示すると、勝手な書き換えを減らせます。専用ツールでも対話型AIでも、「変更が見える」「元に戻せる」は選ぶ際の基本の条件です。

## 表記のルールを守れるかを確認する

仕事で使う文章には、組織や媒体ごとの表記ルールがあります。たとえば、数字は算用数字にそろえる、漢字とひらがなの使い分け、社名や製品名の正式な書き方、といったものです。

AIの校正が一般的な正しさで直すと、ルールとぶつかる場合があります。そこで、次の点を確認します。

- 自分のルールを登録できるか(辞書、用語リスト、指示文の保存など)
- 登録した内容が、次回以降も使われるか
- 固有名詞を勝手に直さないようにできるか
- チームで同じ設定を共有できるか

ルールの登録機能がないツールでは、毎回の依頼文にルールを書くことになります。その場合は、ルールを文書にまとめ、コピーして貼れるようにしておくと、手間を減らせます。例として、次のような短い一覧を作ります。

```
表記ルール:
・数字は算用数字を使う
・「ください」はひらがなで書く
・社名は「株式会社〇〇」と省略しない
・「お客様」を使い、「お客さん」は使わない
```

このようなルールは、チームで共有している指示文の仕組みとも相性が良いものです。共有の考え方は、[うまくいったプロンプトをチームで共有する仕組み](/prompt-team-kyouyuu/)で扱っています。

## 入力した文章の扱いを確かめる

校正ツールには、校正したい文章をそのまま入力します。つまり、未公開の原稿、社内の資料、お客様の情報が含まれる文章を渡す可能性があります。ここは、機能の比較より先に確認したい点です。

確認する項目は次のとおりです。

- 入力した内容が、サービスの改善やモデルの学習に使われる可能性があるか
- 学習に使わない設定が選べるか、それは自分の契約で有効か
- 入力した内容の保存期間と、削除の方法
- 業務で使う場合の、組織のルールや契約形態

これらはサービスごと、契約の種類ごとに違います。公式の利用規約やプライバシーに関する説明を読んで確認してください。確認の進め方は[AIに入力した内容は学習に使われる?確認方法を知ろう](/ai-nyuryoku-gakushuu-riyou/)に詳しく書いてあります。

また、校正を頼むときに、個人名や連絡先、取引先の名前を伏せてから貼る習慣をつけておくと、万一のリスクを減らせます。「〇〇様」のように置き換えて渡し、戻ってきた文章で元に戻す方法です。この一手間で、選べるツールの範囲も広がります。

## 選ぶときのチェックリスト

ここまでの観点を、選ぶ段階で使えるチェックリストにまとめます。気になるツールごとに、次の項目を埋めてみてください。

- 任せたい作業(誤字、表記、文法、文体)に対応しているか
- 自分の文書の種類と長さで使えるか
- 直した箇所が見えるか、元に戻せるか
- 直した理由が分かるか
- 自分の表記ルールを守らせられるか
- 入力した内容の扱いを、公式の情報で確認したか
- 実際の文章で試して、手直しが減ったか
- 日付、数字、固有名詞は、人が最終確認する運用になっているか

最後の2項目が特に大事です。ツールの説明を読んで良さそうに見えても、自分の文章で試すと、意図しない直しが出ることがあります。同じ文章を複数のツールに渡して、直し方を並べて比べると、違いがよく分かります。

試した結果は、ツール名、使った文章、気づいたことを簡単にメモしておきます。時間がたつと、どれがどうだったかを忘れてしまうからです。

## まとめ

AI文章校正ツールの選び方は、次の観点に整理できます。

- 任せたい作業(誤字、表記、文法、文体、事実確認)を先に分ける
- 扱う文書の種類と長さに合うかを確かめる
- 直し方が見えて、元に戻せるかを重視する
- 自分の表記ルールを守らせられるかを確認する
- 入力した文章の扱いを、公式の情報で確認する

どのツールを使っても、最終的な確認は人が行います。ツールは、その確認の手間を減らす道具として選んでください。なお、文章をAIに見てもらうときに自分の文章でいる方法は、[作文をAIに見てもらうとき「自分の文章」でいる方法](/sakubun-ai-tensaku/)にまとめています。
