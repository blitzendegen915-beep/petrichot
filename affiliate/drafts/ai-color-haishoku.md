資料やチラシを作るとき、配色で手が止まることはないでしょうか。色の数が多すぎると雑然として見え、少なすぎると単調になります。センスの問題だと思われがちですが、実際には手順で決められる部分が大きい作業です。

AIは、配色の候補を言葉で出したり、印象に合う色の組み合わせを提案したりするのに使えます。ただし、AIが出した配色をそのまま使うと、見づらかったり、目的に合っていなかったりすることがあります。AIに頼む部分と、自分で決める部分を分けておくと、安定して仕上がります。

この記事では、AIを使って配色を決める手順を順番に説明します。全体の手順は、印象を言葉にする、基調色を決める、候補を出す、読みやすさを確認する、記録する、の5段階です。色の具体的な流行や数値の基準は変わるため、細かい点は公式の情報を参照してください。

## 先に、与えたい印象を言葉にする

配色は、「どんな印象を与えたいか」から決めます。色を直接選ぶより、言葉で印象を決めるほうが、AIにも自分にも判断しやすくなります。

印象を決めるために、次の問いに答えてみてください。

- 誰に向けた資料やチラシか(年齢層、関係、場面)
- 見た人にどう感じてほしいか(安心、元気、上品、信頼、親しみなど)
- 目的は何か(情報を伝える、行動してもらう、雰囲気を伝える)
- 避けたい印象は何か(派手すぎる、冷たい、子どもっぽいなど)
- 使う場所はどこか(画面、印刷、屋外)

答えは、短い言葉で構いません。たとえば、「地域の読み聞かせ会のチラシ。親子向けで、あたたかく親しみやすい雰囲気。派手すぎないこと」のようにまとめます。

この一文が、以降の作業の軸になります。AIに頼むときも、この文をそのまま渡せます。印象があいまいなまま色を選ぶと、いくつ候補を見ても決められません。逆に、印象が言葉になっていれば、候補の中から選ぶ基準ができます。

すでに使っているロゴや、会社・団体の決まった色があるなら、それも書き出しておきます。決まった色がある場合は、それを基調色にして、他の色を合わせるのが基本です。

## 基調色を1つ決め、役割を分ける

次に、基調色を決めます。配色は、色を役割で分けると組み立てやすくなります。

| 役割 | 内容 | 使う場所の例 |
|---|---|---|
| ベースの色 | 面積がいちばん大きい色。背景など | 背景、余白 |
| メインの色 | 印象を決める色 | 見出し、帯、図形 |
| アクセントの色 | 目立たせたい所に少しだけ使う色 | ボタン、強調の言葉 |

目安として、ベースが大半を占め、メインがそれに次ぎ、アクセントはわずかに使います。アクセントを広く使うと、どこを見ればよいか分からなくなります。

基調色を決めるには、印象から連想される色を、AIに複数挙げてもらう方法が使えます。ChatGPTのような対話型AIに、次のように頼めます。

```
次の条件で、メインの色の候補を5つ挙げてください。
・用途:地域の読み聞かせ会のチラシ
・与えたい印象:あたたかく親しみやすい。派手すぎない
・避けたい印象:冷たい、子どもっぽすぎる
それぞれ、色の名前と、その色が与える印象、合わせやすい色を一言で添えてください。
```

AIの答えは、あくまで候補です。実際の色は、画面で見て選びます。言葉で「やわらかい黄色」と言われても、人によって思い浮かべる色は違うからです。気になった候補を、実際にデザインのツールで置いて確かめます。

基調色が決まったら、ベースとアクセントを足します。ベースは白に近い色や、基調色を薄めた色にすると、まとまりやすくなります。アクセントは、基調色と離れた色から選ぶと目立ちますが、色数を増やしすぎないようにしてください。

## 配色の候補を出して、並べて比べる

基調色が決まったら、全体の配色の候補を作ります。AIに頼むと、複数案を短時間で出してもらえます。ここでは、1案ではなく3案ほど出して並べるのがコツです。

依頼文の例は次のとおりです。

```
基調色は「やわらかな黄色」です。これに合わせた配色を3案出してください。
・ベース、メイン、アクセントの3役割で
・それぞれ、色の名前と、使う場所の例を添える
・読みやすさを重視する(文字の色と背景の色の組み合わせを含める)
・案ごとの印象の違いを一言で説明する
```

案が出たら、実際にデザインのツールで色を置いて比べます。例として、Canvaのようなデザインのツールでは、色を指定して図形や文字に適用できます。細かい機能は公式サイトで確認してください。

{{aff:canva}}

比べるときは、同じレイアウトに3案の色を当てはめて、並べて見ます。1案ずつ別々に見ると、差が分かりにくいためです。画面を少し離して、あるいは小さくして見ると、全体の印象がつかめます。

選んだ理由を一言で書いておくと、後で迷いません。「A案は明るいが、アクセントが強すぎるので、B案に決めた」のように残します。

AIが出した色の名前は、人によって見え方が違うことがあります。色の指定は、色の名前だけでなく、色コードなど、再現できる形で記録してください。

## 文字の読みやすさを確認する

配色で最も大切なのが、文字の読みやすさです。きれいな配色でも、文字が読みにくければ、資料としては失敗します。

確認する点は次のとおりです。

- 文字の色と背景の色に、十分な明るさの差があるか
- 薄い色の文字を、薄い背景に載せていないか
- 背景が写真や模様のとき、文字が埋もれていないか
- 小さな文字ほど、色の差を大きくしているか
- 色だけで情報を区別していないか(色の見え方に個人差があるため)

最後の項目は、色の見え方の違いに配慮する視点です。たとえば、グラフで色だけで系列を分けると、色の区別がつきにくい人には読めなくなります。線の形や模様、ラベルを併用すると、伝わりやすくなります。

確認の方法は、白黒に変換して見る、画面を遠くから見る、実際に印刷して見る、などがあります。白黒にして文字が読めるなら、明るさの差は十分である可能性が高いといえます。

読みやすさの具体的な基準値は、ガイドラインとして公開されているものがあります。仕事で使う資料や公的な場面では、公式の情報で確認してください。AIに「この配色は読みやすいか」と聞くこともできますが、判断が不正確な場合があります。最終的には、自分の目と、他の人の目で確かめてください。

## 決めた配色を記録して、再利用する

配色が決まったら、記録します。記録がないと、次の資料で同じ色を再現できず、毎回ゼロから悩むことになります。

記録する項目は次のとおりです。

- 役割(ベース、メイン、アクセント、文字)
- 色コード(画面で再現できる形)
- 使った場所の例
- 決めた理由と、与えたい印象
- 使ってはいけない組み合わせ(読みにくかったもの)

次のような形でまとめておくと、見返しやすくなります。

```
プロジェクト:地域の読み聞かせ会
印象:あたたかく親しみやすい
ベース:(色コード)  用途:背景
メイン:(色コード)  用途:見出し・帯
アクセント:(色コード)  用途:日時・申込の強調
文字:(色コード)  用途:本文
避ける組み合わせ:アクセント色の文字を、メイン色の背景に載せない
```

この記録は、AIに依頼するときにも使えます。「この配色に合わせて、別のチラシの案を考えてください」と渡せば、統一感を保てます。複数の資料でそろえたいときの考え方は、[AI画像のテイストをそろえる方法｜複数枚で統一感を出す](/ai-gazou-tone-soroeru/)も参考になります。

使い終わった配色を保存しておくと、次回は微調整だけで済みます。配色を決める時間が減り、制作全体が楽になります。

また、配色は作る資料ごとに微調整してよいものです。記録はあくまで出発点として使い、場面に合わなければ見直します。

## まとめ

AIを使った配色の決め方は、次の手順です。

- 与えたい印象と、目的や場面を言葉にする
- 基調色を決め、ベース、メイン、アクセントに役割を分ける
- AIに複数案を出してもらい、実際に並べて比べる
- 文字の読みやすさを、白黒表示や印刷で確認する
- 色コードと理由を記録して、次回に使う

AIは候補を出す相手であり、決めるのは自分です。具体的な応用は、[文化祭・部活のポスターをAIで作ってみよう](/bunkasai-ai-poster-tsukurikata/)や、[AIでプレゼン資料を作る方法｜テンプレート活用と進め方](/ai-presentation-shiryou-tsukurikata/)でも使えます。ツールの使い方は[Canva AI（Magic Studio）の使い方｜初心者が失敗しにくい指示文と手順](/canva-ai-design-nyumon/)にまとめられています。
