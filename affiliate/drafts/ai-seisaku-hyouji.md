AIで文章や画像を作ったとき、「AI製」と書くべきなのか。書かなくても問題ないのか。この疑問に、一つの正解はありません。場面によって、求められることが違うからです。

この記事では、「書く・書かない」を決めつけず、判断するための軸と、場面ごとの目安を整理します。法律や各サービスの規約で表示が決まっている場合は、その決まりが優先されます。最新の決まりは、学校や職場、利用するサービスの公式の情報で確認してください。

## 表示を考える三つの軸

表示するかどうかで迷ったとき、役に立つのは次の三つの軸です。それぞれを順に考えると、判断が整理できます。

| 軸 | 問い |
|---|---|
| 決まりがあるか | 学校、職場、投稿先のサービス、コンテストなどに、表示のルールはあるか |
| 受け手に影響するか | AIが関わったと知らないことで、受け手が誤解したり、判断を誤ったりしないか |
| 自分の説明になるか | AIの関与を伝えておくことが、後から自分を守る説明になるか |

一つ目は、最も優先すべき軸です。たとえば、課題やコンテスト、仕事の納品物では、AIの利用に条件がついていることがあります。条件に従わないと、内容がどれほど良くても評価の対象外になる場合があります。まず、決まりの有無を確認することから始めます。

二つ目は、誠実さの軸です。表示がなくても、受け手が困らない場面もあります。たとえば、誤字の確認にAIを使った程度であれば、それを逐一書く必要は感じにくいでしょう。反対に、受け手が「人が実際に見たこと、感じたこと」だと受け取る内容では、AIの関与を伏せたままだと誤解を生みます。

三つ目は、自分を守るための軸です。あとで「これはAIで作ったものか」と聞かれたとき、最初から書いてあれば、説明が簡単になります。逆に、隠していたように見えると、内容に問題がなくても信頼を損なうことがあります。

三つのうち、一つでも「表示したほうがよい」に傾くなら、表示しておくのが安全です。

## 「どこまでがAI製」なのかを分けて考える

「AI製」と一口に言っても、関わり方には幅があります。表示するとしても、どの程度の関与なのかが伝わらないと、受け手には意味が分かりません。そこで、関わり方を大まかに分けてみます。

| 関わり方 | 例 |
|---|---|
| 補助 | 誤字の確認、言い回しの候補出し、アイデアの壁打ち |
| 下書き | AIが出した文案をもとに、人が大きく書き直した |
| 生成 | AIの出力を、ほぼそのまま使った。画像や音声は生成物そのもの |

補助にとどまる場合、表示の必要性は低くなります。文房具や辞書を使うのと近い感覚で、自分の作品と言いやすい範囲です。

下書きの場合は、人がどれだけ手を入れたかが問題になります。AIの文案を読み直して、事実を確かめ、自分の言葉に直しているなら、作品としての責任は自分にあります。ただ、場面によっては「AIの下書きを使った」と添えたほうが、親切な場合があります。

生成の場合は、表示を前向きに考えるべき領域です。特に画像や音声は、見た目だけでは実物と区別がつきにくく、本物の写真や録音だと受け取られる可能性があります。人物の写真のように見える画像や、特定の人の声に似せた音声などは、受け手の誤解につながりやすいので注意が必要です。

画像を仕事で使う前に確認しておくべきことは[AIで作った画像を仕事で使う前に確認しておきたいこと](/ai-gazou-shigoto-riyou-kakunin/)で整理しています。権利の面は[AIと著作権の基本|生成画像や文章は誰のもの?](/ai-to-chosakuken-kihon/)にまとめています。

## 場面ごとの判断の目安

実際の場面に当てはめると、次のようになります。これは目安であって、決まりがある場面ではその決まりが優先されます。

| 場面 | 目安 |
|---|---|
| 学校の課題・レポート | 先生の指示に従う。指示がなければ、使ったことを先生に伝える |
| 就職・進学の書類 | 募集要項の決まりに従う。不明なら問い合わせる |
| 仕事の資料・納品物 | 取引先や社内の決まりに従う。契約や発注の条件を確認 |
| SNSやブログの投稿 | 画像や動画は、生成物であることを添えておくと誤解を防げる |
| 家族や友人への贈り物・カード | 表示は任意。ただし聞かれたら隠さない |
| 実在の人物や出来事を扱う画像・音声 | 生成物と分かる表示を強く勧める |

学校の課題については、[レポート・課題でAIを使うときのルールとマナー](/gakushuu-report-to-ai-no-tsukaikata/)でも触れています。就職の書類のように、AIの使い方が個人の評価に直結する場面は、迷ったら事前に聞くのが安全な方法です。

投稿では、プラットフォームの側に表示の仕組みや規約がある場合もあります。投稿先のヘルプや利用規約を、一度見ておくと安心です。

## 書き方の例文

表示すると決めたら、受け手に伝わる書き方にします。長く説明する必要はなく、「何に」「どう使ったか」が分かれば十分です。

場面ごとの例を挙げます。

```
【画像の場合】
この画像は、AIで生成したものです。
```

```
【文章の下書きに使った場合】
文章の下書きにAIを使い、内容は筆者が確認・修正しています。
```

```
【調べ物の補助に使った場合】
調べる過程でAIを使いました。事実関係は、公式の資料で確認しています。
```

どれも、事実をそのまま書いただけの短い文です。ここで気をつけたいのは、AIの関与を大きく見せることも、小さく見せることもしない、という点です。実際より小さく書けば隠したことになり、実際より大きく書けば、人が確認した部分を見えなくします。

表示の位置は、受け手が自然に目にする場所に置きます。ページの最後の小さな文字に隠すより、画像のそばや文章の冒頭に書いたほうが誠実です。

また、表示は「言い訳」にしないことも大切です。「AIで作ったので間違いがあるかもしれません」と書いて、確認を怠ってよいわけではありません。表示と確認は別の話で、出したものの責任は、出した人が負います。

## 表示で迷ったときに確認すること

最後に、迷ったときの確認事項をまとめます。上から順に見ていけば、結論が出しやすくなります。

1. 学校・職場・投稿先・応募先などに、表示のルールはあるか(あるなら従う)
2. 受け手が、AIの関与を知らないことで誤解する可能性はあるか
3. 画像や音声は、実在の人物や出来事に見えないか
4. 後から聞かれたとき、堂々と説明できる状態か
5. 判断がつかないとき、聞ける相手(先生、上司、窓口)はいるか

五つ目は、見落とされがちな項目です。迷ったときに、決めてくれる人に聞くのは、恥ずかしいことではありません。むしろ、聞かずに進めて問題になるほうが、手間も信頼の損失も大きくなります。

AIで書かれたかどうかを後から見分けることの難しさについては、[AIで書いたかは見分けられるのか｜検出の限界と備え](/ai-de-kaitaka-mikiwame/)で触れています。見分けられないからこそ、自分から正直に伝えることに意味があります。

## まとめ

AI製の表示は、「書けば安全」「書かなければ自由」という単純な話ではありません。決まりがあるか、受け手が誤解しないか、自分の説明になるか、という三つの軸で考えるのが基本です。

補助、下書き、生成という関わり方の違いを分けて考えると、表示の必要性が見えやすくなります。書くと決めたら、何に使ったかを短く、実際のとおりに書きます。迷ったときは、決まりを確かめ、聞ける人に聞く。この順番を守れば、大きく外れることはありません。
