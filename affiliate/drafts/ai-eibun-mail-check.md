英語でメールを書く場面は、増えても、慣れる機会は増えにくいものです。内容は日本語で考えられるのに、英語にしようとすると、丁寧さの加減や言い回しが分からなくなって手が止まります。

AIは、日本語で考えた内容を英語の文章にする作業を、手早く手伝ってくれます。ただし、英文が自然に見えることと、意図が正しく伝わることは別です。読めない英語をそのまま送ると、自分が何を言ったのか分からないまま責任を負うことになります。

この記事では、英文メールをAIで作るときの手順と、送る前に自分で確認する方法を説明します。翻訳全般の使い方と、そのまま出すと危ない場面は[AI翻訳の使い方と、そのまま出すと危ない場面](/ai-honyaku-katsuyou/)で扱っているので、ここでは「メールを作って確認する」流れに絞ります。なお、ビジネス英語の慣習は、相手の国や業界、関係の深さで異なります。ここで紹介するのは一般的な考え方です。

## 英文メールで起きやすい失敗を知っておく

英文メールの失敗は、単語の誤訳よりも、次のような点で起きることがあります。

| 失敗の種類 | 例 | 起きる理由 |
|---|---|---|
| 依頼なのか確認なのか分からない | 「ご確認ください」が、お願いにも報告にも読める | 日本語の言い回しが曖昧なまま英語にした |
| 丁寧さが合っていない | 初対面なのに砕けすぎ、親しい相手なのに堅すぎる | 相手との関係をAIに伝えていない |
| 日付や時刻の取り違え | 月と日の順番、時差、締め切りの基準 | 表記の違いと、地域の違いに気づいていない |
| 数字や固有名詞の誤り | 金額、型番、人名のつづりが変わる | AIが書き換えた、または元の入力が誤っていた |
| 日本語の前提が通じない | 「よろしくお願いします」を直訳して意味不明になる | 日本語特有のあいさつを、そのまま訳した |

とくに最後の項目に注意が必要です。日本語のメールでは、「お世話になっております」や「よろしくお願いいたします」を毎回書きます。英語のメールでは、同じ意味の決まり文句を、そのまま入れる必要はありません。AIに直訳させると、不自然な、または大げさな文になることがあります。

そのため、日本語の文章をそのまま渡して「英語にして」と頼むより、「何を伝えたいのか」を先に整理して渡すほうが、良い結果になります。

## まず日本語で骨子を書く

英文を作る前に、日本語で「伝える内容の骨子」を書き出します。きれいな文章にする必要はありません。箇条書きで十分です。

骨子に入れる項目は、次のとおりです。

1. **誰に送るか**: 相手の立場(取引先、初対面の相手、社内の海外拠点など)と、これまでの関係
2. **目的**: お願いなのか、報告なのか、質問なのか、お礼なのか
3. **相手にしてほしいこと**: 具体的に何を、いつまでに
4. **伝えるべき事実**: 日付、時刻(時間帯の基準も)、金額、数量、型番
5. **避けたい印象**: 強く催促に見えないように、など

目的と、相手にしてほしいことは、1つのメールに1つずつにまとめると、相手が読みやすくなります。複数の依頼を詰め込むと、見落とされることがあります。

骨子の例を示します。

```
相手: 取引先の担当者。何度かメールのやり取りがある
目的: 先週送った見積書の確認状況を聞く(催促に見えないように)
してほしいこと: 確認できたら、承認か修正点かを知らせてほしい
期限: 【日付】までに返事がほしい
事実: 見積書の送付日は【日付】、書類名は【ファイル名】
```

このメモを書く段階で、自分が何を伝えたいのかが整理されます。曖昧な部分があれば、ここで気づけます。曖昧なまま英語にしても、曖昧な英文ができるだけです。

## AIに英文を作らせる依頼文

骨子ができたら、AIに英文を頼みます。ClaudeやChatGPTのような対話型のAIは、例として挙げられる選択肢のひとつです。社内で使ってよいサービスが決まっている場合は、そちらを使ってください。機能や条件は、各公式サイトで確認します。

{{aff:claude}}

依頼文の例を示します。

```
次の骨子をもとに、英文メールの下書きを作ってください。

骨子:
【上のメモを貼る】

条件:
- 相手との関係は「何度かやり取りのある取引先」。丁寧だが、堅すぎない文体
- 件名も作る
- 日付は月を英単語で書き、数字だけの表記にしない
- 骨子に書かれていない事実や約束を足さない
- 日本語のあいさつの直訳(お世話になっております等)は入れず、英語で自然な書き出しにする
- 作った英文とは別に、その英文を日本語に訳し直したものを付ける
- 迷った表現があれば、候補を2つ出して違いを説明する
```

この依頼文のポイントは3つあります。

- 日付を「月を英単語で書く」と指定することで、月と日の取り違えを防ぎます
- 「足さない」と指定することで、AIが勝手に約束を作るのを防ぎます
- 「日本語に訳し直したものを付ける」と指定することで、次の確認作業の材料が得られます

3つ目は、英語に自信がない人にとって大切な工夫です。英文だけを渡されても、内容が合っているか判断できません。日本語の訳が付いていれば、骨子と見比べられます。ただし、AIが付ける訳は、英文の意味ではなく元の骨子に寄せて書かれることがあります。そのため、次の節で説明する別の確認も行います。

## 送る前の確認：逆翻訳と読み比べ

AIが作った英文を確認する方法を、順に説明します。英語が得意でなくても、できる方法です。

1. **別の会話で逆翻訳する**: 新しい会話を開き、英文だけを貼って「この英文を日本語に訳してください」と頼む。元の骨子と比べて、意味がずれていないか見る。最初の会話の文脈が残っていると、元の意図に寄せて訳されることがあるため、新しい会話で行う
2. **骨子と1つずつ照合する**: 骨子の項目(目的、お願い、期限、事実)が、英文に全部入っているか。逆に、骨子にない内容が増えていないか
3. **数字と固有名詞を、元の資料と見比べる**: 日付、金額、型番、人名と会社名のつづり。AIが書き換えたり、丸めたりしていないか
4. **依頼の強さを読む**: お願いなのか命令に聞こえないか、催促が強すぎないか。AIに「この英文は、受け手にどんな印象を与えそうですか。強すぎる、または弱すぎる点があれば指摘してください」と頼むのも1つの方法
5. **短くできないか考える**: 長いメールは、相手にとって読みにくい。一文を短く、依頼は先頭近くに

これらを行っても、不安が残る場合があります。重要な契約や、法的な意味を持つ内容、トラブルの対応を含むメールは、英語に詳しい人や専門家に確認してもらってください。AIの確認は補助であって、責任を取ってくれるわけではありません。

また、別の観点として、AIの回答は質問のたびに変わることがあります。同じ骨子でも、頼み直すと別の表現が出てきます。内容が食い違うときの考え方は、[AIの回答が食い違うときの確かめ方](/ai-kaitou-kuichigai/)が参考になります。

## 送信前の点検表と、機密の扱い

最後に、送る前の点検表です。メールの末尾の確認として、毎回使えます。

- 件名は、内容を表しているか
- 依頼は何で、期限はいつか、読んだだけで分かるか
- 日付は月を英単語で書いてあるか。時刻に時間帯の基準(どの地域の時間か)を添えたか
- 数字、固有名詞、型番は、元の資料と一致しているか
- 骨子にない約束、謝罪、条件が入っていないか
- 日本語特有のあいさつの直訳が残っていないか
- 添付ファイルは付いているか、本文の記載と一致しているか
- 宛先(To、Cc、Bcc)は正しいか

さらに、AIに入力する内容にも注意が必要です。取引先の名前、金額、契約の内容、個人情報などをそのまま入力してよいかは、会社のルールやAIサービスの扱いによって違います。判断に迷う場合は、固有名詞を伏せ字にした骨子で英文を作り、送る前に自分で差し替える方法があります。差し替えのときは、入れ忘れや入れ間違いが起きやすいため、点検表で確認してください。

返信が来たときも、同じ流れで使えます。相手の英文を新しい会話に貼り、「要点と、こちらに求められていることを、日本語で整理してください。推測せず、書かれていることだけで答えてください」と頼みます。そのうえで、重要な部分は原文を自分でも読んでください。メールの文章全般の見直し方は、[AIが書いた文章の直し方](/ai-bunshou-teisei/)が参考になります。

## まとめ

英文メールをAIで作るときは、日本語で骨子を決め、AIに英文化を頼み、人が確認する、という流れをとります。

- 失敗は誤訳よりも、依頼が曖昧、丁寧さのずれ、日付や数字の取り違えで起きやすい
- 先に日本語の骨子(相手、目的、してほしいこと、事実)を書く
- 依頼文で「足さない」「日付は月を英単語で」「日本語に訳し直しも付ける」と指定する
- 別の会話で逆翻訳し、骨子や元の資料と見比べる
- 重要な内容は、英語に詳しい人にも確認してもらう
- 送信前に点検表で、数字、宛先、添付を確認する

英語を書く場面は、準備の仕方で負担が変わります。次に英文メールを書くときは、まず日本語の骨子を3行で書くところから始めてみてください。

何度か繰り返すうちに、自分がよく使う依頼や断りの型が見えてきます。うまくいった骨子と依頼文は保存しておくと、次回は日付と事実を入れ替えるだけで済みます。英語の力そのものを伸ばしたい場合は、AIが出した英文の言い回しを、自分の表現として少しずつ覚えていく使い方もあります。AIに頼りきりにならず、自分で読んで意味が分かる英文だけを送る、という線を守ってください。
