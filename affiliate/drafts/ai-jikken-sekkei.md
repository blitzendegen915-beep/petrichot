「このAIは文章が得意」「あのAIは計算が弱い」。こうした評判は、ニュースやSNSで目にします。ただ、その評判が自分の使い方にも当てはまるかは、試してみないと分かりません。

この記事では、AIの得意・不得意を自分で確かめるための、小さな実験のやり方を紹介します。大げさな準備は要りません。ノートと少しの時間があれば始められます。実験の目的は、AIを評価することではなく、自分がどの場面でAIを頼ってよいかを知ることです。

## 実験の出発点は「自分の使い方に関する問い」

実験は、問いを立てるところから始まります。ここで大切なのは、「AIは賢いか」といった漠然とした問いを避け、自分の使い方に直結する具体的な問いにすることです。

問いの良し悪しは、次の例で比べると分かります。

| 漠然とした問い | 具体的な問い |
|---|---|
| AIは文章が上手か | 自分が書く丁寧なメールの下書きを、そのまま送れる水準で作れるか |
| AIは計算に強いか | 家計の月ごとの合計を出す作業を、間違えずに任せられるか |
| AIは正確か | 自分の専門分野の用語の説明を、教科書と食い違わず答えられるか |
| AIは要約が得意か | 自分が読む報告書の要点を、抜けなく三行にまとめられるか |

具体的な問いは、「そのまま送れる」「間違えずに」「食い違わず」「抜けなく」のように、合格かどうかの基準が問いの中に入っています。これにより、結果を見たときに、答えが「はい」か「いいえ」かで判断しやすくなります。

問いを立てるコツは、普段の暮らしや仕事で、AIに任せたいと思っている作業を一つ選ぶことです。まだ任せてよいか迷っている作業ほど、実験する価値があります。

一度に複数の問いを立てないことも大切です。問いが多いと、何を確かめているのか分からなくなります。一回の実験では、問いを一つだけにします。

## 条件をそろえる｜変えるのは一つだけ

実験で最も重要なのは、条件をそろえることです。複数のAIを比べたり、指示文を変えて比べたりしたいときも、変えるのは一度に一つだけにします。

たとえば、「AIのAとBのどちらが要約に向くか」を調べたいなら、次の点をそろえます。

- 同じ元の文章を使う
- 同じ指示文を使う
- 同じ日に試す(途中でサービスの状態が変わるのを避けるため)
- 結果の採点基準を、先に決めておく

採点基準は、結果を見る前に決めるのが原則です。見てから決めると、気に入った結果に合わせて基準を動かしてしまいます。

基準の例を挙げます。要約の実験なら、次のようにします。

1. 元の文章の重要な点が、抜けずに入っているか(自分で事前に三つ選んでおく)
2. 元の文章にない内容が、勝手に足されていないか
3. 指定した長さに収まっているか
4. そのまま使える読みやすさか

それぞれ「できている・不十分・できていない」の三段階で採点します。細かい点数をつけるより、三段階で十分です。

実験で使う題材は、個人情報や社外秘の内容を含まないものを選びます。公開されている文章や、自分で作った練習用の文章を使えば、安心して試せます。

## 同じことを何回か試して、ばらつきを見る

AIの回答は、同じ指示でも毎回少しずつ変わることがあります。そのため、一回だけの結果で判断するのは危険です。一回うまくいったから得意、一回失敗したから不得意、とは決められません。

そこで、同じ指示文で、複数回試します。回数は多いほどよいというわけではなく、数回で傾向をつかむ程度で十分です。

見るべきなのは、次の二点です。

| 見る点 | 意味 |
|---|---|
| 平均的な出来 | だいたいどの程度の水準か |
| ばらつき | 出来がよいときと悪いときの差が大きいか |

ばらつきが大きい場合は、そのままでは任せにくい作業だと考えられます。出来がよいときもあるのに、悪いときの結果が目立たないと、気づかずに出してしまう危険があるからです。逆に、ばらつきが小さく、毎回安定しているなら、確認の手間を減らせる可能性があります。

もう一つ、別の言い方で聞いてみる試し方もあります。同じ内容を、表現を変えて頼んだとき、答えの中身が大きく変わるかを見ます。中身が変わるなら、AIの答えが指示の書き方に左右されやすい作業ということです。

食い違いが出たときの確かめ方は、[AIの回答が食い違うときの確かめ方](/ai-kaitou-kuichigai/)で詳しく扱っています。実験で食い違いが出たときの見方にも役立ちます。

## 結果を記録して、パターンを見つける

実験は、記録を残して初めて意味を持ちます。頭の中の印象だけでは、後で「なんとなく良かった」としか残りません。

記録は、次のような表をノートか表計算ソフトに作るだけで十分です。

| 日付 | 問い | 使ったAI | 指示文(要点) | 採点 | 気づいたこと |
|---|---|---|---|---|---|
| | | | | | |

指示文は、全文を残すと後で再現できます。長い場合は、別のファイルに貼っておき、表には識別できる名前だけを書きます。

「気づいたこと」の欄が、実験の最大の収穫になります。たとえば、次のような気づきです。

- 固有名詞が入る文章では、間違いが増える
- 長い手順を一度に頼むと、途中の項目が抜ける
- 数字を含む表を作らせると、合計が合わないことがある
- 丁寧な言葉づかいの指定は、守られやすい

こうした気づきが溜まると、「この作業は任せられる」「この作業は自分で確認が要る」という線引きが、自分の経験から作れます。人の評判より、自分の記録のほうが、自分の使い方には当てはまりやすいはずです。

数え間違いや計算といった、AIが間違えやすい作業の例は、[AIが苦手なこともある｜数え間違い・計算・長い手順での確かめ方](/ai-nigate-kazoeru-keisan/)にあります。実験の題材を選ぶときのヒントにしてください。

## 結果の読み方と、やってはいけない読み方

実験の結果を読むときには、いくつか注意が必要です。

一つ目は、「この実験の範囲でだけ言えること」を超えて決めつけないことです。要約を数回試して良好だったからといって、あらゆる文章で要約が得意だとは言えません。結果は、「自分が試した題材と条件では」という前置きつきで受け取ります。

二つ目は、結果が古くなる可能性を忘れないことです。AIのサービスは、更新によって挙動が変わることがあります。数か月前の実験結果が、今も当てはまるとは限りません。気になる作業は、時間をおいて再度試します。AIの情報の新しさについては、[AIは最新のことを知っている？「いつ時点か」の確かめ方](/ai-saishin-joho-shiranai/)も参考になります。

三つ目は、うまくいかなかった結果を、価値のない結果として捨てないことです。「これは任せられない」と分かったことは、大事な成果です。無駄な確認作業を省く判断にも、危ない使い方を避ける判断にもつながります。

他人の実験結果や、一般的なランキングと自分の結果が違っていても、気にしなくて構いません。使う題材も、頼み方も違うからです。ランキングや点数の読み方は、[AIの性能比較はどう読む？ランキングと点数の見方の基本](/ai-seinou-hikaku-yomikata/)で整理しています。

## まとめ

AIの得意・不得意は、評判を聞くより、自分の題材で小さく試して確かめるほうが、使い方の判断に役立ちます。問いは具体的に一つ、条件は変えるものを一つ、採点基準は先に決める。同じことを数回試して、ばらつきを見る。結果は表に記録し、気づいたことを溜める。この流れで十分です。

結果は、試した範囲の中でだけ言えることだと考え、時間がたったら再び試します。「任せられない」と分かることも、立派な成果です。まずは今日、普段の作業の中から一つ選んで、最初の問いを書いてみてください。
