AIに質問したのに、読んでみると「聞きたかったのはそこじゃない」と感じたことはないでしょうか。指示文の書き方を工夫する前に、じつはもっと手前に原因があることがあります。それは、**自分が何を知りたいのか、自分でもはっきりしていない**という状態です。

この記事では、AIに文字を打ち込む前にやっておく「知りたいことの整理」を扱います。指示文の型そのものについては[AIへの指示文(プロンプト)の書き方基本ガイド](/prompt-no-kakikata-kihon/)で説明しています。ここでは、その一つ手前の段階、つまり頭の中のもやもやを、質問の形にするまでの手順に絞ります。

中学生や高校生のみなさんが調べものに使う場面でも、社会人が仕事の相談に使う場面でも、考え方は同じです。

## 質問がぼやけると、答えもぼやける

AIは、書かれた質問から答えを作ります。質問に書かれていないことは、AIが推測して補います。ここに、食い違いが生まれる原因があります。

たとえば「環境問題について教えて」と送ったとします。この質問には、次のことが書かれていません。

- 何のために知りたいのか(授業の発表なのか、ただの興味なのか)
- どのくらい詳しく知りたいのか
- すでに何を知っているのか
- 答えをどう使うのか

書かれていないので、AIは「一般的な解説」を返すしかありません。環境問題の種類を並べた、教科書の目次のような文章が返ってくることが多いでしょう。それは間違いではありませんが、あなたが本当に知りたかったことではないかもしれません。

ここで大事なのは、これはAIの能力の問題とは限らない、ということです。人に質問するときを考えてみてください。先生に「環境問題について教えてください」とだけ聞いたら、先生もまず「何を知りたいの？」と聞き返すはずです。AIは聞き返してくれるときもあれば、そのまま答えてしまうときもあります。聞き返してもらうのを待つより、最初から自分で整理しておくほうが、やり取りは少なく済みます。

次の表は、整理していない質問と、整理した質問の違いを並べたものです。

| 項目 | 整理していない質問 | 整理した質問 |
|---|---|---|
| きっかけ | 書かれていない | 授業で発表することになった |
| 知りたいこと | 環境問題全般 | 身近な例で説明できる話題を一つ選びたい |
| 自分の状態 | 書かれていない | ニュースで見たことはあるが、説明はできない |
| 答えの使い道 | 書かれていない | 発表の題材を決める材料にする |
| 返してほしい形 | 書かれていない | 候補を3つ、それぞれ一言の説明つきで |

右の列の情報を書いておくだけで、返ってくる答えの方向がそろいます。次の節からは、この右の列を作るための手順です。

## 手順1｜まず「何のために知りたいか」を一文で書く

質問を作る最初の一歩は、AIに聞く内容ではなく、**自分の目的**を書き出すことです。

目的は、「〜のために、〜を知りたい」という形で一文にします。ここでは完璧な文でなくて構いません。メモ帳に自分用に書くだけです。

- 来週の発表の題材を決めるために、候補を知りたい
- 友だちとの意見のちがいを整理するために、論点を知りたい
- 自分の書いた説明が合っているか確かめるために、足りない点を知りたい
- 初めて聞いた言葉の意味を、ざっくりつかむために、短い説明がほしい

こうして書いてみると、「知りたい」の中身は、実はいくつかの種類に分かれることに気づきます。

| 目的の種類 | 例 | AIに頼む内容 |
|---|---|---|
| 候補を出したい | 発表の題材を決めたい | 選択肢を並べてもらう |
| 理解したい | 仕組みをつかみたい | 説明してもらう |
| 確かめたい | 自分の考えが合っているか見たい | 点検してもらう |
| 整理したい | 頭の中が散らかっている | 分類や順序づけを手伝ってもらう |
| 比べたい | AとBのどちらにするか迷う | 比べる観点を出してもらう |

自分の目的がどの種類かが分かると、頼み方が決まります。「候補を出したい」のに「説明してください」と頼むと、長い解説が返ってきて、候補が見つかりません。反対に「確かめたい」のに「教えてください」と頼むと、自分の考えと関係のない話が返ってきます。

目的を書いても、うまく一文にならないときがあります。それは、まだ考えがまとまっていないという合図です。その場合は、次の手順に進んで、材料を集めてからもう一度戻ってきてください。

## 手順2｜「いま知っていること」と「分からないこと」を分ける

目的が決まったら、次は自分の現在地を確認します。ここでやるのは、紙やメモ帳を二つの欄に分けることです。

- 左の欄: いま知っていること、聞いたことがあること
- 右の欄: 分からないこと、あいまいなこと

たとえば、「光合成について調べたい」という場面で書いてみます。

| いま知っていること | 分からないこと |
|---|---|
| 植物が光を使うこと | 光のエネルギーがどう使われるのか |
| 二酸化炭素と関係がありそうなこと | 夜はどうなるのか |
| 葉の緑色と関係がありそうなこと | なぜ秋に葉の色が変わるのか |

この表を作ると、「光合成を教えて」という漠然とした質問が、「夜の植物は光合成をしないのか、呼吸との関係で知りたい」というように、具体的な問いに変わります。

この作業には、もう一つよい点があります。**AIの答えが正しいかどうかを判断する足場ができる**ことです。自分が何を知っていて何を知らないのかが見えていれば、答えを読んだときに「ここは知っていた内容と合っている」「ここは初めて聞いたから、別の資料でも確認しよう」と、受け取り方を分けられます。AIの答えには、もっともらしい間違いが混じることがあります。その仕組みは[AIはなぜもっともらしい嘘をつくのか](/ai-hallucination-naze/)で説明しています。自分の現在地を知っておくことは、その確認の入口にもなります。

右の欄が空のままのときは、本当に分かっているか、分かったつもりなのかを疑ってみてください。声に出して誰かに説明するつもりで言ってみて、詰まるところが、右の欄に入る項目です。

## 手順3｜答えの「使い道」と「形」を決める

整理の三つ目は、返ってきた答えを**何に使うか**と**どんな形で受け取りたいか**です。ここを決めないと、答えが長すぎたり、使いにくい形で返ってきたりします。

まず使い道です。次のように自分に聞いてみてください。

- この答えを読んだあと、自分は何をするのか(発表のスライドを作る、メモに写す、人に相談する、など)
- この答えは、そのまま使うのか、材料として使うのか
- 誰かに見せるのか、自分だけが読むのか

次に形です。同じ内容でも、受け取り方によって使いやすさが大きく変わります。

| 受け取りたい形 | 向いている場面 |
|---|---|
| 短い一言の説明 | 知らない言葉の意味をつかみたいとき |
| 箇条書きの候補 | 題材やアイデアを選びたいとき |
| 表での比較 | 二つ以上のものを比べたいとき |
| 手順の番号つき一覧 | 作業のやり方を知りたいとき |
| 質問への反論や弱点 | 自分の意見を点検したいとき |

形の指定については、[AIの回答をいつも同じ形式で受け取るコツ](/ai-shutsuryoku-format-kotei/)でより詳しく扱っています。ここでは「形を決めてから聞く」という順番だけ覚えておけば十分です。

使い道が決まると、もう一つ利点があります。**どこまで聞けば終わりか**が分かることです。発表の題材を一つ決めたいだけなら、候補が出た時点で目的は果たせています。それ以上聞き続けると、情報が増えて、かえって決めにくくなります。

## 整理したメモを、一つの質問文にまとめる

ここまでの手順で、次の四つの材料が手元にそろいました。

1. 目的(何のために知りたいか)
2. 現在地(知っていることと、分からないこと)
3. 使い道(答えをどうするか)
4. 形(どんな形で受け取りたいか)

この四つを、そのまま文章につなげれば、質問文ができあがります。次の枠をコピーして、かっこの中を自分のメモで置きかえてみてください。

```text
【目的】
(目的)のために、質問します。

【いま知っていること】
(左の欄の内容)

【分からないこと】
(右の欄の内容。特に知りたい点を一つ選ぶ)

【答えの使い道】
(答えを読んだあと、自分は何をするか)

【受け取りたい形】
(箇条書き、表、短い説明など)

【お願い】
分からない点や、前提が足りない点があれば、答える前に私に質問してください。
```

最後の「お願い」の一文は、特に役に立ちます。AIが前提を勝手に推測して答えを作る前に、足りない情報を聞き返してくれる可能性が高まるからです。聞き返してくれたら、それは質問が整理しきれていなかった所を教えてくれているわけですから、その部分をメモに足して、もう一度送ってみましょう。

実際の記入例を一つ示します。

```text
【目的】
来週の授業で、環境問題について短い時間で発表します。その題材を決めるために、質問します。

【いま知っていること】
ごみの分別や、海のプラスチックのニュースを見たことがあります。

【分からないこと】
身近な例で、中学生に説明しやすい題材はどれか。

【答えの使い道】
候補から一つ選んで、資料作りを始めます。

【受け取りたい形】
候補を3つ、理由を一言ずつ添えて、箇条書きでお願いします。

【お願い】
前提が足りない点があれば、答える前に質問してください。
```

ChatGPTのような対話型のAIは、こうした長めの質問文を貼りつけて使うことができます。使える機能や条件はサービスによって異なるため、詳細は公式サイトで確認してください。

## 返ってきた答えを見て、質問を育てる

質問文を送って終わり、ではありません。返ってきた答えを読んだら、次の三つを自分に聞いてみてください。

- 聞きたかったことに答えているか
- 答えを読んで、新しく分からなくなったことはあるか
- 答えの中で、自分の目的に関係ない部分はどこか

答えがずれていたときは、AIを責める前に、四つの材料のどこが足りなかったかを見直します。多くの場合、原因は次のどれかです。

| ずれ方 | 疑う場所 | 直し方 |
|---|---|---|
| 内容が広すぎる | 目的、分からないこと | 特に知りたい点を一つに絞る |
| 難しすぎる、易しすぎる | 現在地 | 学年や立場、知っている範囲を書き足す |
| 長すぎる、使いにくい | 形 | 字数や形式を指定する |
| 的外れな話が混じる | 使い道 | 答えをどう使うかを書き足す |

直したら、同じ会話の中で続きの質問として送って構いません。最初の質問を全部書き直す必要はありません。「いまの答えは広すぎました。〜に絞って、もう一度お願いします」と伝えるだけで、方向が変わります。

もう一つ、質問を育てるコツがあります。それは、**答えを読んで新しく出てきた疑問を、次の質問の材料にする**ことです。最初の質問で完璧な答えを得ようとしなくて構いません。会話を二、三往復して、少しずつ知りたいことを絞っていく使い方でも、十分に整理の役に立ちます。

会話が長くなってきたら、そのつど「ここまでで分かったこと」を自分の言葉でメモしておくと、頭の中が散らかりません。

## まとめ｜整理する習慣はAIの外でも役に立つ

ここまでの手順は、AIのために作ったものではありません。目的を決め、現在地を確かめ、使い道を考えるという流れは、人に質問するときにも、図書館や検索で調べものをするときにも、同じように使えます。

先生や先輩に質問するときも、「何が分からないのか」を整理して持っていくと、相手は答えやすくなります。

AIとの会話は、その練習の場にもなります。質問を整理して送ると答えが良くなり、整理しないと答えがぼやける。この違いを何度も体験できるからです。

最後に、送る前の確認事項をまとめます。

- 何のために知りたいのか、一文で言える
- 自分が知っていることと、分からないことを分けて書いた
- 答えをどう使うか決めた
- 受け取りたい形を決めた
- 分からない点があれば聞き返してほしい、と書いた
- 個人情報や、他人に見せたくない内容を含めていない

最後の項目は、整理とは別に、いつも確認してほしいことです。入力してよい内容については[AIと個人情報|入力していいこと・ダメなこと](/ai-to-privacy-kojinjouhou/)で詳しく説明しています。

ここまでの内容を、あらためて振り返ります。

AIに聞く前の整理は、難しいことではありません。目的、現在地、使い道、形の四つを、メモ帳に書き出すだけです。

- 質問が曖昧だと、AIは推測で補い、答えもぼやける
- 目的を「〜のために、〜を知りたい」の一文で書く
- 知っていることと分からないことを、二つの欄に分ける
- 答えの使い道と、受け取りたい形を先に決める
- 四つの材料を一つの質問文にまとめ、聞き返してほしいと添える
- 答えがずれたら、どの材料が足りなかったかを見直す

整理に使った時間は、あとで答えを読み直したり、聞き直したりする時間を減らしてくれます。そして何より、整理の過程で自分の考えがはっきりするので、AIに聞く前に答えが見えてしまうこともあります。それも、整理のよい効果の一つです。
