画像生成で、偶然すごく気に入った絵ができた。ところが、あとで同じような絵を作ろうとしても、どうしても同じ雰囲気にならない。こうした経験は、画像生成を使っていると起こります。

原因の多くは、「どんな条件で作ったか」を記録していなかったことです。プロンプト(指示文)だけを控えていても、再現には足りないことがあります。使ったツールの種類や版、設定、参照した画像など、結果に影響する要素が他にもあるからです。

この記事では、画像生成のプロンプトと関連情報を記録して、あとから再現・改善できるようにする方法を紹介します。記録の項目、表の作り方、ファイルの名前の付け方、再現できないときの考え方、改善の記録の取り方の順に説明します。ツールごとの設定項目や、再現性の仕様は異なるため、細かい点は公式サイトのドキュメントで確認してください。プロンプトの書き方そのものは、[Midjourneyプロンプトのコツ10選](/midjourney-prompt-no-kotsu/)が参考になります。

## 記録しておきたい項目を決める

記録する項目は、「同じ条件を再び用意できるか」という視点で決めます。少なすぎると再現できず、多すぎると続きません。次の項目を基本にしてください。

| 項目 | 記録する内容 | 理由 |
|---|---|---|
| 日付 | 作った日 | ツールの更新との関係を追える |
| ツール名と版 | 使ったサービスと、選んだモデルや版 | 版が変わると結果が変わる |
| プロンプト | 入力した指示文の全文 | 再現の中心 |
| 設定 | 縦横比、品質、スタイルなどの設定 | 同じ指示文でも設定で変わる |
| 参照画像 | 参考にした画像、その出どころ | 結果に影響し、権利の確認にも必要 |
| 乱数の指定 | 乱数を固定する設定があれば、その値 | 再現性を高める手がかり |
| 結果 | 出力した画像のファイル名 | 指示文と結果を結びつける |
| 評価 | 良かった点、直したい点 | 改善の手がかり |

乱数の指定については、ツールによって、そのような設定があるものとないものがあります。設定の名前や意味は異なるため、使っているツールの公式ドキュメントで確認してください。あるツールで有効だった設定が、別のツールには存在しない場合もあります。

「全部は面倒」と感じる場合は、最低限の3つ(ツール名と版、プロンプト全文、設定)から始めます。残りは、気に入った絵ができたときだけ追加で書く、という運用でも続けやすくなります。

記録は、うまくいった絵だけでなく、うまくいかなかった絵も残すと、あとで役に立ちます。「この言葉を入れると、こう崩れた」という失敗の記録は、次の指示文を書くときの手がかりになるからです。

## 記録表とコピー用のひな形を作る

項目が決まったら、記録の置き場所を決めます。表計算の表、ノートツール、テキストファイルなど、続けやすいものを選んでください。ノートツールの例として、Notionのようなものがあります。機能は公式サイトで確認してください。

最も手軽なのは、次のひな形を、そのたびにコピーして書く方法です。

```
日付:
ツール・版:
プロンプト:
設定:
参照画像:
乱数の指定:
結果のファイル名:
評価(良い点・直したい点):
次に試すこと:
```

表にする場合は、1行を1枚の絵として、上の項目を列にします。列の並びは、プロンプトを左側、結果を右側に置くと、見比べやすくなります。

置き場所を選ぶときの観点は、次のとおりです。

- 画像そのものと、記録を同じ場所に置けるか(別々だと対応が崩れる)
- 検索できるか(キーワードで過去の記録を探せるか)
- 複数人で共有できるか(チームで使う場合)
- ツールを替えても、記録を持ち出せるか

チームで使う場合は、[うまくいったプロンプトをチームで共有する仕組み](/prompt-team-kyouyuu/)の考え方が使えます。誰が見ても同じ手順で再現できる記録にしておくと、担当が変わっても作業が続けられます。

画像を保存するときは、記録表の項目と対応する名前を付けます。次の節で、その付け方を説明します。

## ファイルの名前と、フォルダの整理

画像ファイルの名前は、後から探せるように決めます。生成ツールが付ける名前のままだと、どの絵がどの記録に対応するか分からなくなるからです。

名前の付け方の例は次のとおりです。

```
2026-11-04_poster-bg_v1.png
2026-11-04_poster-bg_v2.png
2026-11-05_poster-bg_v2-color.png
```

並びは「日付_用途_版」とします。日付が先頭にあると、並べたときに時系列で見られます。用途の部分に案件名や目的を入れると、フォルダを開いたとき何の絵か分かります。版の番号は、プロンプトを少し変えるたびに増やします。

フォルダは、案件ごとに分けて、その中に「採用」「候補」「没」を置く方法が分かりやすいです。没にした絵も、すぐには消さずにしばらく置いておくと、あとで「やっぱりあちらが良かった」というときに戻れます。

複数枚をそろえて使う場合は、基準にした1枚を決め、その記録を目立つ場所に置きます。複数枚の画風をそろえる方法は[AI画像のテイストをそろえる方法｜複数枚で統一感を出す](/ai-gazou-tone-soroeru/)で解説しています。基準の1枚の記録があれば、あとから追加の絵を作るときも、同じ条件で始められます。

元の画像は、編集する前のものを別に残します。手直しをした画像は「v2-color」のように、何を直したかが分かる名前にします。ファイル名だけで、その絵の履歴をたどれるようにしておくのがねらいです。

## 同じ絵にならない理由を知っておく

記録を残していても、完全に同じ絵を作れないことがあります。理由を知っておくと、落ち着いて対処できます。

再現が難しくなる主な理由は次のとおりです。

- ツールの内部のモデルが更新され、同じ指示文でも結果が変わった
- 生成のたびに、乱数によって結果が変わる仕組みになっている
- 選んだ版や設定が、前回と違っていた
- 参照画像が、前回と違うものだった
- ツール側の仕様変更で、設定の意味が変わった

特に、モデルの更新は避けられません。サービスは改良され続けるため、数か月前と同じ指示文でも、雰囲気が変わることがあります。そのため、再現は「完全な一致」ではなく、「近い雰囲気に戻せること」を目標にすると現実的です。

再現がうまくいかないときは、次の順で調べます。

1. 記録した版と設定が、今の画面で選べるか確認する
2. 参照画像を同じものに戻す
3. 乱数を固定できるなら固定し、同じ指示文を試す
4. 近づかなければ、指示文を少しずつ調整して、差分を記録する

それでも一致しないときは、元の画像を基準にして、近い雰囲気に調整します。元の画像を保存しておけば、画像を参考にして近づける方法もあります(対応はツールによります)。思った絵にならない場合の見直し方は、[AI画像が思った絵にならないときの直し方](/ai-gazou-omotta-to-chigau/)でも扱っています。

## 改善の記録は「差分」で取る

記録の目的は、再現だけではありません。うまくいった絵を、もっと良くするためにも使えます。そのときに役立つのが、差分の記録です。

差分の記録とは、前の版から何を変えたかを書くことです。たとえば、次のように残します。

```
v1 → v2:背景の指定を「森」から「木漏れ日の森」に変更
結果:光の表現が増えたが、人物が小さくなった
v2 → v3:人物を「中央に大きく」と追加
結果:バランスが改善。色が少し暗い
```

1回に変えるのは、1か所だけにします。複数を同時に変えると、どの変更が結果に効いたのか分からなくなるからです。少しずつ変えて、そのたびに記録する。この繰り返しが、結局は近道になります。

差分の記録がたまると、「自分が使うと効果的な言葉」と「効果が出ない言葉」が見えてきます。それを自分用の言葉のメモにまとめると、次の制作が速くなります。

最後に、記録を見直す習慣を持ちます。月に1回程度、記録を開いて、よく使う指示文を整理します。効果のあった表現は「定番」としてまとめ、外れた表現は「避ける」に分けます。定番のメモは、次の案件の出発点になります。

Midjourneyのような画像生成ツールでは、プロンプトや設定のやり方が独自の形になっています。使っているツールの公式の説明を読んで、自分の記録の項目に合わせてください。

## まとめ

画像生成のプロンプトを管理して再現するには、次の流れを使います。

- 再現に必要な項目(ツールと版、プロンプト全文、設定、参照画像、結果)を決める
- コピー用のひな形か記録表を作り、続けられる場所に置く
- ファイル名に日付、用途、版を入れ、フォルダを整理する
- 完全な一致は難しいと理解し、近い雰囲気に戻せることを目標にする
- 変更は1回に1か所とし、差分を記録して改善に使う

記録は手間に感じられますが、気に入った絵が二度と作れなくなる困りごとを減らしてくれます。まずは最低限の3項目から、小さく始めてください。
