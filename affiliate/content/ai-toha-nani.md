「AI」「ChatGPT」「生成AI」という言葉、最近よく聞きませんか？ニュースでも学校でも話題になっているけれど、正体がいまいちわからない。そんなふうに感じている人もいると思います。この記事では、AIが何をしている道具なのかを、できるだけかんたんな言葉で説明します。

読み終えたときに、「AIは何が得意で何が苦手か」を自分の言葉で説明できて、実際にAIを使うときの最初の一歩と、答えの確かめ方がわかる状態を目指します。

## AIって何？身近な場面で見てみよう

AIは「Artificial Intelligence」の略で、日本語では「人工知能」と言います。ひとことで言うと、**コンピュータが、人間が考えているようなことを、まねしてやってみせる技術**のことです。

「考えている」と言っても、人間のように気持ちや意思をもって考えているわけではありません。ここは後の節でもう一度ふれます。

実は、AIはもう私たちの生活のいろいろな場面に入りこんでいます。

- **スマートフォンの予測変換**：LINEやメールを打つとき、次に使いそうな言葉を候補に出してくれます。よく使う言葉を覚えて、次を予想しているのです
- **動画アプリのおすすめ**：自分が見た動画をもとに「こういうのが好きそう」と選んで並べてくれます
- **翻訳アプリ**：英語の文章を日本語にしたり、カメラで写した看板を訳したりできます
- **写真アプリの顔認識**：カメラが顔を見つけてピントを合わせたり、写真を人ごとに分けたりします
- **ゲームの敵キャラ**：プレイヤーの動きに合わせて動きを変えるものがあります

どれも「データを見て、次はこうなりそうだと予想する」という点が共通しています。AIは遠い未来の技術ではなく、毎日の中でもうお世話になっているものです。

小学生の弟や妹に説明したいときは、[AIってなに？小学生にもわかる図で説明します](/ai-toha-nani-shougakusei/)が図つきで読みやすいので、一緒に見てみるのもおすすめです。

## 従来のAIと生成AI、何が違う？

最近よく聞く「生成AI」は、AIの中の一つのタイプです。ここを区別できると、ニュースが読みやすくなります。

### 従来のAI：「判定する・選ぶ」AI

昔からあるタイプのAIは、主に**「これは何か」を判定したり、候補の中から選んだりする**役割をしてきました。

- 迷惑メールの振り分け：「このメールは迷惑メールか、ふつうのメールか」を判定する
- 動画のおすすめ：たくさんある動画の中から、見てもらえそうなものを選ぶ
- 写真の顔認識：「ここに顔がある」と見つけ出す

### 生成AI：「作る」AI

ChatGPTのような生成AIは、**文章や画像などを、指示に合わせてその場で作り出す**ことができます。

- 「英語の短い物語を書いて」と頼むと、物語を書いてくれる
- 「この文章をていねいな言い方に直して」と頼むと、書き直してくれる
- 「かわいい猫のイラストを描いて」と頼むと、新しい絵を作ってくれる

違いをまとめると、次のようになります。

| | 従来のAI | 生成AI |
|---|---|---|
| 主な役割 | 判定する、選ぶ | 文章や画像を作る |
| 身近な例 | 迷惑メール判定、おすすめ動画 | 文章作成、イラスト作成、文章の書き直し |
| 出てくるもの | 「迷惑メール」「そうでない」などの判定結果 | 文章、画像など新しい作品 |
| 使う人がすること | 自動で動くので、意識しないことが多い | 自分で指示を書いて頼む |

生成AIの代表的なサービスのひとつがChatGPTです。ほかにも、ClaudeやGeminiのように、文章で質問して答えてもらうタイプのサービスがあります。どんなものか気になる人は、下のリンクから見てみてください。

## AIはどうやって答えているの？

「AIが考える」と言っても、人間の考え方とは違います。仕組みの細かい話は専門的なので、ここでは**大づかみな考え方**だけにします。

1. **たくさんのデータから学ぶ**：AIは、文章や画像などを大量に読みこんで学習します
2. **パターンを覚える**：「この言葉のあとには、こういう言葉が続きやすい」といった、よくある並び方を覚えます
3. **パターンをもとに答えを組み立てる**：質問されると、学んだパターンから「それらしい答え」を作ります

スマートフォンの予測変換を思い出してください。「ありがとう」と打つと、次に「ございます」が出てきますよね。生成AIは、これをものすごく大きくしたようなものだと考えると、イメージしやすくなります。

ここで大事なのは、**AIは「正しいかどうか」を確かめて答えているのではなく、「それらしいかどうか」で答えを作っている**ということです。だから、もっともらしく書いてあるのに間違っている、ということが起きます。理由はこちらの[AIはなぜもっともらしい嘘をつくのか](/ai-hallucination-naze/)で詳しく説明しています。

## AIが得意なことと、苦手なこと

AIは便利ですが、万能ではありません。得意なことと苦手なことを知っておくと、「ここはAIに任せよう」「ここは自分でやろう」と分けられるようになります。

| 場面 | AIが得意なこと | AIが苦手なこと（人が気をつけること） |
|---|---|---|
| 文章 | 下書きを作る、言い換える、短くまとめる | 事実や人名、日付が正しいかの保証。間違いを自信ありげに書くことがある |
| 勉強 | 難しい言葉をやさしく説明する、例を出す | 学校のテストの範囲や先生の方針に合わせること |
| 発想 | アイデアをたくさん出す、整理する | 自分が本当にやりたいことを決めること |
| 計算 | 解き方の流れを説明する | 計算の答えそのものは間違えることがある。電卓や検算で確かめる |
| 最新情報 | （使うサービスによっては調べられるものもある） | 学習した時点より新しい出来事は知らないことがある |
| 気持ち | 気持ちに寄りそうような言葉を返す | 人の気持ちを本当に理解しているわけではない。大事な相談は身近な大人に |
| 判断 | 選択肢と、それぞれの良い点悪い点を並べる | 何が正しいか、何を選ぶべきかを決めること |

表を見ると、AIは「材料を出す」「たたき台を作る」のが得意で、「最後に決める」「正しさを確かめる」のは人間の仕事だとわかります。

宿題や課題にAIを使うときは、学校や先生のルールを必ず確認してください。「答えを写す」のではなく「考えるための相手にする」使い方が、自分のためになります。

## はじめてAIに聞くときの質問例

どう聞けばいいかわからない人は、次の文章をそのままコピーして、「　」の部分を自分のテーマに変えて使ってみてください。

**例1：わからない言葉を説明してもらう**

```
中学生にもわかるように、「光合成」を説明してください。
身近なたとえを1つ入れて、最後に「確認クイズ」を3問出してください。
```

**例2：自分の文章を直してもらう（答えを作ってもらうのではなく、チェックしてもらう）**

```
次の文章は私が書いた読書感想文です。
内容は変えずに、わかりにくい部分と、言い回しがおかしい部分を指摘してください。
書き直した文章は出さず、直す方向のヒントだけ教えてください。
（ここに自分の文章を貼る）
```

**例3：AIの答えの弱点を、AI自身に挙げてもらう**

```
さっきの説明の中で、間違っている可能性がある部分や、
自分で確認したほうがいい部分があれば教えてください。
```

聞き方のコツは3つです。

- **誰向けの説明か**を伝える（「中学生向けに」など）
- **どんな形で**ほしいかを伝える（「箇条書きで」「3つだけ」など）
- **やってほしくないこと**も書く（「答えは出さずにヒントだけ」など）

名前、住所、電話番号、学校名など、自分や友達が特定されるような情報は、入力しないようにしましょう。

## AIの答えを確かめる3ステップ

AIの答えは、そのまま信じず、次の3ステップで確かめる習慣をつけましょう。

1. **数字・名前・日付に印をつける**：間違いが混ざりやすいのは、こうした具体的な部分です
2. **別の情報源で確かめる**：教科書、学校の資料、図書館の本、公的機関のサイトなど、もとの資料に近いものを見ます。AIが書いた文章をもう一度AIに聞くだけでは、確認になりません
3. **おかしいと思ったら聞き返す**：「その根拠は何ですか？」「間違いの可能性はありますか？」と聞いてみます。ただし、聞き返した答えもまた確かめる必要があります

確かめた結果、AIの答えが間違っていたときは、**そのまま使わず、正しい情報をもとに自分で書き直す**のがいちばん安全です。「どこが間違っていたか」をメモしておくと、次からAIの弱点が見えるようになります。

AIとの付き合い方を、もう少しくわしく知りたい人は、[知っておきたいAIリテラシーの基本](/ai-riteracy-nyuumon/)も読んでみてください。

## まとめ

AIは、予測変換や動画のおすすめなど、すでに身近なところで使われている技術です。生成AIの登場で、「判定する」だけでなく「文章や画像を作る」こともできるようになりました。

ただし、AIは「それらしい答え」を作っているので、間違うこともあります。得意なのは材料を出すことやたたき台を作ることで、最後に決めること、正しさを確かめることは自分の役目です。

まずは短い質問を1つ、AIに聞いてみて、答えを3ステップで確かめてみてください。その経験が、これからAIと付き合っていくときの土台になります。将来のことが気になる人は、[AI時代の進路と仕事はどうなる？](/ai-jidai-no-shinro/)も参考になります。
