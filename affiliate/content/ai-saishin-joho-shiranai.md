「今年の大会、誰が優勝したの？」「この前出た新しいゲーム機、いくらだっけ？」。こんなふうに、何でも答えてくれそうなAIに、つい最近のことを聞いてみたくなることがあります。

けれども、対話型AIは、いつでも「今」のことを知っているわけではありません。しかも、知らないときに「知りません」と言わず、それらしい答えを返してしまうことがあります。この記事では、その理由をやさしく説明し、日付や「今」が関わる質問のときにどう確かめればよいかを、そのまま使える質問文といっしょに紹介します。

## AIの知識には「ここまで」という区切りがある

対話型AIは、とても多くの文章を読んで、言葉の使われ方を学んでいます。ただ、その学習には「ここまで」という区切りがあります。区切りの日までに集められた文章から学んで、そこで学習がいったん終わる、というイメージです。

たとえ話で考えてみましょう。ある日までの新聞を全部読んだ人がいるとします。この人は、その日までの出来事にはとても詳しく、昔の歴史も、言葉の意味も、よく知っています。でも、その日より後に起きたことは、新聞を読んでいないので知りません。

この人に「昨日の試合の結果は？」と聞いても、答えようがないはずです。ここで大事なのは、AIがこの人と少し違うところです。AIは、会話しているあいだにも、自分の知識がどこで止まっているかを、いつもはっきり意識しているわけではありません。また、質問した人が「今」の話をしているのか、昔の話をしているのかも、文章から読み取るしかありません。

もう一つ、知っておきたいことがあります。AIを使う私たちは、AIがいつ学習を終えたのかを、画面を見ただけでは分からないことがあります。使っている日と、学習の区切りの日とのあいだには、すき間があります。そのすき間に起きたことは、AIにとっては「読んでいない新聞」の中の話です。

だから、AIの答えを受け取るときは、中身が正しいかどうかだけでなく「これはいつ時点の話だろう」と一歩立ち止まる習慣が役に立ちます。区切りの日付は、ツールによっても、使っている時期によっても違います。この記事では特定のツールの日付には触れませんので、気になるときは各サービスの公式サイトの説明で確かめてください。

## 知らないのに、答えてしまう場面

では、区切りより後のことを聞くと、AIはどう答えるのでしょうか。いくつかの場面で見てみましょう。

### 今年の大会の結果を聞いたとき

たとえば「今年の大会の優勝者は？」と聞いたとします。AIが区切りより前の情報しか持っていないと、前の年の優勝者を、そのまま「今年の優勝者」として答えてしまうことがあります。答え方は自信ありげなので、読んだ側は、間違いに気づきにくくなります。

### 最近発売された商品について聞いたとき

「最近発売された〇〇の新型の特徴を教えて」と聞くと、その商品が区切りより後に出ていた場合、AIはその商品の情報を持っていません。このとき、前の型の特徴を新型の説明として答えたり、それらしい特徴をつなぎ合わせて答えたりすることがあります。商品名を出したのに、中身は別の商品の話になっている、ということです。

### 学校の制度やルールについて聞いたとき

「今の入試の仕組みは？」「いまの校則のルールは？」のような質問も要注意です。制度やルールは、年ごとに見直されることがあります。AIが学んだ時点の説明が、今の説明と同じとは限りません。古い仕組みを、今も続いているものとして説明してしまうおそれがあります。

### 共通しているのは「知らないと言わない」こと

三つの場面に共通しているのは、AIが「その情報は持っていません」と言わずに、手元にある古い情報や、それらしい文章で答えを作ってしまう点です。この現象は、AIがもっともらしい間違いを答える問題と深くつながっています。くわしくは、別の記事「[AIはなぜもっともらしい嘘をつくのか](/ai-hallucination-naze/)」で説明しています。

古い情報をそのまま答える場合も、知らないことをそれらしく作ってしまう場合も、AIに悪気があるわけではありません。ただ、読む側が「今の話として使ってよいか」を確かめないと、間違った情報をそのまま友だちに話したり、宿題に書いたりしてしまいます。

## 最新の情報が必要な質問と、そうでない質問

すべての質問で、区切りが問題になるわけではありません。質問の種類によって、影響の受けやすさが大きく変わります。次の表で、大まかに分けてみましょう。

| 質問の種類 | 区切りの影響 | 例 |
|---|---|---|
| 言葉の意味を調べる | 受けにくい | 「慣用句の意味を教えて」 |
| 文章を直す | 受けにくい | 「この作文の読みやすさを直して」 |
| 考えを整理する | 受けにくい | 「発表の内容を三つの柱にまとめたい」 |
| 昔から変わらない考え方の説明 | 受けにくい | 「分数の割り算の考え方を説明して」 |
| ニュースや最近の出来事 | 受けやすい | 「先週の出来事を教えて」 |
| 商品の値段や新製品 | 受けやすい | 「この商品はいま何円？」 |
| ルールや制度 | 受けやすい | 「いまの入試制度はどうなっている？」 |
| 発売日や公開日 | 受けやすい | 「新作の発売日はいつ？」 |
| 試合結果や順位 | 受けやすい | 「昨日の試合の結果は？」 |

表の上半分は、答えが「今日かどうか」にあまり左右されない質問です。言葉の意味や文章の直し方は、あなたが渡した文章をもとに作業するので、AIの知識の区切りはほとんど関係しません。

表の下半分は、答えが日によって変わる質問です。ニュース、値段、ルール、発売日、試合結果など、「今」が答えの一部になっているものは、区切りの影響を受けやすくなります。

迷ったときの見分け方は簡単です。その質問の答えは「来月になったら変わっているかもしれない」でしょうか。変わりそうなら、AIの答えをそのまま使わないほうが安心です。変わらなさそうなら、AIの得意な仕事であることが多いです。ただし、これは目安です。昔からある考え方の説明でも、新しい研究で言い方が変わっていることはあります。

## 確かめ方｜質問文の実物とあわせて

「今」が関わる質問のときの確かめ方は、大きく三つあります。順番に見ていきましょう。

### 一つ目：AIに「いつ時点の情報ですか」と聞く

いちばん手軽なのは、AIにそのまま聞くことです。答えのあとに、次のように続けてみてください。

```
今の答えは、いつ時点の情報にもとづいていますか。
あなたが確実に知っている範囲と、知らないかもしれない範囲を分けて教えてください。
```

「ニュースを聞くとき」には、最初から条件をつけておく方法もあります。

```
最近の出来事について聞きます。もし最新の情報を持っていない場合は、
知らないと正直に答えてください。推測で答えるときは、推測だと書いてください。
```

こう聞くと、AIが「私の知識はここまでなので、それより後のことは知らない可能性があります」のように、範囲を説明してくれることがあります。ただし、これは確かめ方の入り口にすぎません。AI自身が自分の区切りを正しく言えるとは限らないので、返ってきた答えもうのみにはしないでください。

### 二つ目：ウェブを検索してから答えるツールを使う

世の中には、質問を受けると、ウェブを検索して、見つけた情報をもとに答えを作るタイプのツールがあります。最近の出来事を聞きたいときは、こうしたツールのほうが向いています。AIの中にしまってある知識だけに頼らず、その場で探した情報を使えるからです。

AI検索と従来の検索の違いは「[AI検索は従来の検索と何が違う?](/ai-kensaku-perplexity-hikaku/)」でくわしく比べています。検索してから答えるタイプのツールの考え方を知りたい人は、あわせて読んでみてください。

Perplexityのような、検索してから答えるタイプのツールでは、答えの近くに、どのページを見たのかを示す出典が並ぶ仕組みを持つものがあります。「今」が関わる質問をするときは、こうしたツールの出番です。使える機能や範囲は、サービスやプランによって違うことがあるので、公式サイトで確かめてから使ってください。

### 三つ目：元の情報源を自分で開く

三つ目は、いちばん確実な方法です。試合結果なら大会の公式サイト、商品の値段や発売日ならメーカーや販売店のページ、入試や校則なら学校や教育委員会の案内を、自分で開いて読みます。

AIの答えは「どこを見に行けばよいか」を知るための手がかりとして使い、最後の確認は元の情報源でする、と決めておくと迷いません。

## 検索してから答えるツールでも、出典を開いて確かめる

検索してから答えるタイプのツールなら、もう安心かというと、そうではありません。気をつけたい点がいくつかあります。

まず、ツールが探してきたページが、必ずしも正しいとは限りません。ウェブには、古いまま残っているページや、うわさをもとに書かれたページもあります。検索で見つけた情報をもとに答えていても、その情報が古ければ、答えも古くなります。

次に、ツールが出典をまとめて文章にするとき、ページに書いてある内容と少しずれてしまうことがあります。出典として並んでいるページを開いたら、答えに書かれていたことが載っていなかった、という場面も考えられます。

そこで、出典が示されたときは、次の手順で確かめてみてください。

- 出典のリンクを実際に開く
- ページに、答えと同じことが書かれているかを読む
- そのページの日付や、更新された日を探す
- 学校や会社、大会などの公式なページかどうかを見る
- 一つのページだけでなく、別のページにも同じことが書かれているかを見る

ほかにも、ChatGPTのような対話型のサービスで、ウェブを調べる機能が使えるものがあります。ただし、どんな条件で使えるかはサービスや時期によって変わります。画面に検索を使っている様子が出ているか、出典が示されているかを、その都度見て確かめてください。検索を使っていない普通の答えなのか、検索した答えなのかが分からないまま使うのは避けましょう。

## 使う前のチェック項目

AIの答えを宿題や発表、友だちとの会話で使う前に、次の項目を見直してみてください。

- この質問は、ニュース、値段、ルール、発売日、試合結果のような「今」が関わるものか
- AIの答えに、年や日付、「現在」「最新」といった言葉が出てきているか
- その情報が、いつ時点のものかを、AIに聞いて確かめたか
- 検索してから答えるタイプのツールを使ったか、使っていないか
- 出典が示されていれば、実際にリンクを開いて読んだか
- 出典のページの日付や更新日は、今の話として使えるものか
- 公式サイトなど、元の情報源でも確かめたか
- 確かめられなかった部分を、「たぶん」「未確認」としてメモしたか
- 学校の宿題や発表に使うなら、先生や保護者にも確かめてもらったか

すべてを毎回やる必要はありません。答えが間違っていたときの困り方が大きいものほど、念入りに確かめる、という考え方で十分です。

## まとめ

対話型AIの知識には、学習の「区切り」があります。区切りより後に起きたことは知らないことがあり、しかも知らないのに、もっともらしく答えてしまうことがあります。

言葉の意味、文章の直し、考えの整理のような質問は、区切りの影響を受けにくい仕事です。ニュース、値段、ルールや制度、発売日、試合結果のように「今」が関わる質問は、AIの答えをそのまま使わないようにしましょう。

確かめ方は三つでした。AIに「いつ時点の情報ですか」と聞くこと、ウェブを検索してから答えるタイプのツールを使うこと、そして元の情報源を自分で開くことです。検索つきのツールを使うときも、出典を開いて内容と日付を確かめる習慣をつけましょう。

AIは、うまく使えば心強い助けになります。「これはいつ時点の話だろう」と一歩立ち止まるだけで、AIとのつきあい方は、ぐっと安全になります。
