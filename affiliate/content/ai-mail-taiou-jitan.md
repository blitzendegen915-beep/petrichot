朝、受信箱を開くと未読が並んでいて、返信を書いているうちに午前が終わる。営業職や管理職、問い合わせ窓口の担当者、一人で仕事をしている個人事業主なら、思い当たる光景ではないでしょうか。

一方で、すべてのメールをAIに任せるわけにはいきません。顧客への謝罪、金額や契約の話、人事にかかわる連絡など、責任が伴う内容は人が判断して書く必要があります。

そこで大切なのが、「どこまでAIに任せ、どこからは自分で書くか」の線引きです。この記事では、メール対応のどの工程をAIで短くできるのか、そのまま貼って使える依頼文の実物、任せてよいメールと任せないメールの分け方、そして送信前の確認手順までをまとめます。

## メール対応で時間がかかっている場所を分ける

メール対応が重いのは、返信を打つ時間だけが理由ではありません。1通ごとに、次のような作業が積み重なっています。

- **読んで理解する**: 長い経緯のスレッドから、相手が何を求めているかを拾う
- **優先順位を決める**: どれを先に返し、どれは後回しでよいかを判断する
- **文面を組み立てる**: 相手の立場や関係の深さに合わせて言い回しを選ぶ
- **定型の挨拶や言い回しを毎回打つ**: 内容は違っても、前後の形はほぼ同じ
- **送る前に見直す**: 宛名、日付、金額、トーンの確認

この中で、AIが力を発揮しやすいのは「読んで理解する」「文面のたたき台を作る」「定型を整える」の3つです。反対に、「優先順位を決める」「相手との関係を踏まえて最終的に何を約束するかを決める」「送る前に見直す」は、人の仕事として残ります。

つまりAIで短くできるのは、白紙から書き始める時間と、長い文章を読み解く時間です。判断と責任は短くできませんし、短くしてはいけません。この前提を持っておくと、あとの線引きが迷いにくくなります。

たとえば、取引先から経緯の長いスレッドの最後に「ご確認をお願いします」とだけ届いたとします。何を確認すればよいのかを探す作業はAIに手伝わせられますが、確認した結果として「はい、その条件で進めます」と答えるかどうかは、人が決めることです。

## AIに任せるメールと、人が判断するメールの分け方

最初に、メールの種類ごとの線引きを表にします。迷ったときは、「間違えたときに取り返しがつくか」「相手との約束や責任が生まれるか」で考えると整理しやすくなります。

| メールの種類 | 扱い方 | 理由・注意点 |
|---|---|---|
| 長いメールの要点整理、分類 | AIに任せてよい | 読み手が内容を確認できる。結果は自分の目で原文と照らす |
| 日程調整、資料送付の連絡 | 下書きをAIに任せてよい | 候補日時や添付の有無は人が入れて確認する |
| 軽いお断り、見送りの連絡 | 下書きをAIに任せ、人が仕上げる | 関係の深さによって言い回しの調整が必要 |
| 定型のお礼、あいさつ | AIで型を作り、使い回す | 宛名と固有名詞の差し替え漏れに注意 |
| クレーム対応、お詫び | 人が書く(骨子の整理だけAIに相談可) | 何があったか、どう対処するかは当事者にしか書けない |
| 金額、納期、契約条件が絡むもの | 人が判断して書く | 誤りが約束や損害につながる。AIの文案をそのまま使わない |
| 人事、評価、採用、退職にかかわるもの | 人が判断して書く | 個人情報が多く、言葉の選び方が相手の生活に影響する |
| 新しい提案や方針の通知 | 人が書く | 判断の背景や考えを自分の言葉で伝える必要がある |

表の下半分は、AIを使わないというより、「判断と最終的な文言は人が持つ」という意味です。たとえばクレームの返信でも、「経緯の整理」や「読みやすい構成の相談」にAIを使う余地はあります。ただし、お詫びの言葉、原因の説明、再発防止の約束は、事実を知っている人が書き、上司や関係部署の確認を通してください。

また、社内で取り決めがある場合はそれが優先です。メールの内容をAIに入力してよいか、どのサービスなら使ってよいかは、会社ごとに違います。この点は後の節で詳しく触れます。

## 長いメールを読み解く：要点整理と分類の依頼文

最初に取り入れやすいのは、受信メールの要点整理です。長いスレッドを読み返す手間が減り、返信の優先順位も付けやすくなります。

ChatGPTやClaudeのような対話型のAIに、次のような依頼文を貼ってみてください。`【 】` の部分を自分の状況に合わせて書き換えます。

```
以下のメール(スレッド)を読んで、次の4点を箇条書きで整理してください。
1. 相手が求めていること
2. 回答や対応の期限(書かれていなければ「記載なし」)
3. 私が決めなければならないこと
4. 本文からは読み取れない、確認が必要な点
推測で補わず、本文に書かれていることだけで答えてください。

【ここにメール本文を貼る(個人名や社名は伏せ字にしたもの)】
```

ポイントは、「推測で補わず」と書くことと、「記載なし」の逃げ道を用意することです。AIは書かれていない期限や条件を、それらしく補ってしまうことがあります。逃げ道を指定しておくと、補われた内容と原文を混同するリスクを減らせます。

複数のメールを分類したいときは、次のように頼みます。

```
次の3通の問い合わせメールを、「至急返信が必要」「今日中に返信」「確認のみで返信不要」の3つに分類し、理由を一行ずつ添えてください。判断の根拠は本文中の表現に限ってください。

【メール1】…
【メール2】…
【メール3】…
```

分類の結果は参考であり、最終的な優先順位は自分で決めます。「確認のみ」に入ったメールに、実は期限付きの依頼が紛れていた、ということもあり得るためです。AIが要約や分類をしたあとも、重要そうなメールは必ず原文を一度は開いてください。

英語のメールを受け取る場合は、「日本語で要点を整理して、返信が必要な箇所に印を付けて」と頼むと、読む負担が軽くなります。ただし、契約や数字にかかわる部分は、翻訳の誤りがないか原文で確かめてください。

依頼文を試す対話型AIとしては、ChatGPTなどがあります。使える機能や条件は変わることがあるので、公式サイトで確かめてから使ってください。

## 返信の下書きを作る依頼文：場面別の実物

返信文は、白紙から書くより、たたき台を直すほうが取りかかりが軽くなります。ここでは場面ごとに、条件まで書いた依頼文を示します。AIの出力が不安定になる主な原因は、「誰に」「何を」「どのくらいの距離感で」が抜けていることです。

**日程調整の返信**

```
取引先の担当者に、打ち合わせ日程の候補を伝えるメールの下書きを書いてください。
- 相手: 初めて日程調整をする取引先の担当者(敬語は丁寧に)
- 候補日時: 【10月○日(○)午後】【10月○日(○)午前】
- 所要時間の目安: 【1時間】
- 形式: 【オンライン】。URLは後ほど送ると書く
- 長さ: 本文は5〜7行程度。挨拶は簡潔に
```

**依頼や提案を断るメール**

```
次の依頼を、角を立てずにお断りするメールの下書きを書いてください。
- 依頼の内容: 【○○の制作依頼】
- 断る理由: 【現在、受けられる件数がいっぱいで対応できないため】(詳しい事情は書かない)
- 関係: 【今後も付き合いのある取引先】なので、感謝を述べ、また相談してほしい旨を入れる
- 避けたいこと: 代替案の約束はしない。曖昧に期待を持たせない
```

お断りの文面で大切なのは、はっきり断ることと、相手への敬意を両立させることです。「検討します」のような曖昧な書き方になっていないか、下書きを読んで確認してください。

**お詫びメールの「骨子」を整える**

お詫びの本文そのものはAIに任せませんが、何を書くべきかの整理には使えます。

```
納期が遅れたことへのお詫びメールを書くために、盛り込むべき項目を整理したいです。
文章は書かず、項目と並べる順番の案だけを出してください。
状況: 【納品が数日遅れる。原因は社内の確認待ち。新しい納品予定日は決まっている】
```

出てきた項目(お詫び、事実の経緯、新しい予定、今後の対応)をもとに、自分の言葉で本文を書きます。原因を実際より軽く見せる表現や、確定していない約束が入っていないか、書き終えたら見直してください。

メールに限らず、案内文や報告文などの下書きをまとめて作りたい場合は、文章作成に特化したツールを使う方法もあります。どんな文章に向くかや使える機能は、公式サイトで確かめてください。

Value AI Writerのようなツールは、同じ調子で相手ごとに文面を作り分けたい場面で候補になります。どこまでできるかは公式サイトで確認してください。

## AIに貼る前の確認：個人情報と社外秘

ここまで読んで、「顧客のメールをそのままAIに貼って大丈夫なのか」と気になった方もいるでしょう。結論から言うと、まず会社のルールを確認するのが先です。

メール本文には、相手の氏名、連絡先、取引の条件、社内の状況など、外に出してはいけない情報がよく含まれます。AIサービスに入力した内容が、サービス側でどう扱われるかは、サービスや契約内容によって異なります。個人で契約したアカウントと、会社が契約した環境とでも条件が違う場合があります。

貼る前の手順は次のとおりです。

- **社内ルールを確認する**: 業務データをAIサービスに入力してよいか、使ってよいサービスが決まっているかを、情報システム部門や上司に確かめる。ルールが無い場合や不明な場合は、顧客情報を含むメールは貼らない
- **サービス側の設定を確認する**: 入力内容が学習に使われるかどうかなどの設定は、サービスごとに公式の案内で確認する
- **伏せ字にしてから貼る**: 氏名は「A社の○○様」のように置き換え、電話番号、住所、メールアドレス、口座情報、案件名や金額の具体値は削る
- **貼らないと決めるものを持つ**: 人事、病気や家族の事情、未発表の情報、契約書の条文など、伏せ字にしても内容から推測できるものは最初から渡さない
- **返信は元に戻して使う**: AIの下書きにある「A社」を、送る前に正しい宛名に戻す。置き換え漏れも確認する

伏せ字にすると、実はAIにとって困ることはあまりありません。要点整理や文面の下書きに、相手の本名は必要ないからです。個人情報の扱い全般は、[AIと個人情報|入力していいこと・ダメなこと](/ai-to-privacy-kojinjouhou/)も参考にしてください。

## 朝の流れと、送信前の確認手順

最後に、1日の流れとして組み立てます。受信箱を丸ごとAIに貼ると、何が含まれているかを確認しないまま外部に送ることになるため、避けてください。

1. **自分で仕分ける**: 「返信必須」「確認のみ」「対応不要」にざっと分ける。ここは人が判断する
2. **AIに渡せるものを選ぶ**: 顧客情報や社外秘が含まれるものは渡さない。迷うものは渡さない側に寄せる
3. **伏せ字にして、要点整理や下書きを依頼する**: 前節までの依頼文を使う
4. **下書きを自分の言葉に直す**: 言い回し、距離感、約束の中身を調整する
5. **送信前の確認をして送る**

送信前の確認は、AIの下書きでも、自分で一から書いたメールでも、同じ手順で行います。

- 宛名と社名、敬称は正しいか。伏せ字の置き換え漏れ(「A社」など)は残っていないか
- 日付、曜日、時刻、金額、数量、納期は、元の資料や元のメールと突き合わせたか
- 添付ファイルと、本文で言及した資料は付いているか
- 本文で約束したこと(いつまでに、誰が)は、自分が実際に守れる内容か
- 宛先(To、Cc、Bcc)は正しいか。返信を全員に送ってよいか
- 相手が受け取って不快になりそうな言い回しはないか。声に出して読むと気づきやすい

これらは、AIの下書きでは特に起きやすい失敗と重なります。たとえば、AIがもっともらしい日付や条件を補ってしまった、前のやり取りと矛盾する内容が入っていた、というものです。

もし誤ったメールを送ってしまったら、気づいた時点で早めに訂正の連絡を入れてください。「先ほどのメールの○○は誤りでした。正しくは○○です」と簡潔に書き、お詫びを添えます。取引や金額が絡む場合は、上司や関係者にもすぐ共有します。

## まとめ

メール対応をAIで短くできるのは、長い文章を読み解く時間と、白紙から書き始める時間です。一方で、何を約束し、どう責任を持つかの判断は人が持ち続けます。

- 要点整理、分類、日程調整やお断りの下書き、定型文づくりは、AIに任せやすい
- クレーム、金額や契約、人事、新しい提案は、人が判断して書く
- 貼る前に社内ルールを確認し、氏名や金額は伏せ字にする
- 送る前に、宛名、数字、約束、宛先を自分の目で確認する

依頼文の精度を上げたい場合は、[AIへの指示文(プロンプト)の書き方基本ガイド](/prompt-no-kakikata-kihon/)も役立ちます。まずは次の1通で、要点整理の依頼文を試してみてください。
