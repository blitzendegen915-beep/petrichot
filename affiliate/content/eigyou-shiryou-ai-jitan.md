「明日の商談までに提案書を仕上げなければならないのに、まだ真っ白なスライドしか開いていない」――営業や企画の仕事をしていると、こうした状況に何度も直面します。営業資料・提案書の作成は、内容を考えること以上に、ページ割りやレイアウト、素材探しに時間を取られがちです。本記事では、AIに任せてよい作業と、人が決めるべき内容をはっきり分けたうえで、提案書づくりの手順を具体的に紹介します。小さな会社で営業も資料作りも一人でこなしている方を想定しています。

## 時間がかかる工程と、AIに任せる範囲を分ける

まず、営業資料・提案書を作る一連の流れを分解してみましょう。

| 工程 | 内容 | 時間がかかりやすい理由 |
|---|---|---|
| 構成づくり | 目次・ストーリーラインの設計 | ゼロから考えるのは負荷が高い |
| スライド作成 | レイアウト・デザインへの落とし込み | 装飾やページ割りに手間がかかる |
| ビジュアル準備 | 図解・イメージ画像の用意 | 素材探しや作成に手間がかかる |
| 仕上げ・確認 | 誤字脱字、数字の整合性チェック | 提出前の見直しは省けない |

この中で、AIの助けを借りやすいのは「構成づくり」「スライド作成」「ビジュアル準備」です。一方で、提案書の中身そのものまでAIに決めさせると、どこの会社にも当てはまる薄い資料になりかねません。次の表を、作業を始める前の線引きとして使ってください。

| 項目 | AIに任せてよい | 人が決める |
|---|---|---|
| 顧客固有の課題の把握 | 聞き取りメモの整理、論点の洗い出し | 実際に何に困っているかの見立て |
| 提案の構成・ページ割り | 目次案、章立ての複数案 | どの案を採用するかの判断 |
| 文章の言い回し | 箇条書きの文章化、敬語の整え | 相手との関係に合う温度感 |
| 価格・費用感 | 見積項目の並べ方の案 | 金額、値引きの可否、支払条件 |
| 約束する内容 | 約束事項の書き方の案 | 納期、対応範囲、保証の有無 |
| 実績の数字・事例 | 数字を表やグラフにする形の提案 | 数字そのもの、掲載の許可 |
| イメージ画像 | 表紙や区切りの画像の生成 | 画像が内容と誤解なく合うかの確認 |

判断の目安は単純で、**間違えたときに相手との約束や信用に響く項目は、人が決める**ということです。価格、納期、実績の数字をAIに考えさせないだけで、事故の大半は避けられます。

## 提案書の骨組みを作る依頼文

構成づくりで一番つまずきやすいのは、「AIに頼んだら、もっともらしい数字や事例まで勝手に書かれた」という点です。これを防ぐには、依頼文の中で項目の置き場所を指定し、材料にないことは書かせない条件を付けます。次の依頼文は、ChatGPTやClaudeなどの対話型AIにそのまま貼って使えます。【】の部分を、自分の案件の内容に置き換えてください。

```
あなたは法人営業の提案書づくりを手伝うアシスタントです。
下の【材料】だけを使って、提案書の骨組みを作ってください。

【材料】
・相手先：【業種・規模・担当者の役職】
・相手の課題（聞き取った内容）：【箇条書きで】
・こちらの提案内容：【サービス名と、やることの概要】
・根拠にできる材料：【自社の実績・事例・資料があれば箇条書き。なければ「なし」】
・費用感：【決まっていれば記載。未定なら「未定」】
・次の一歩：【例：来週デモを実施、見積書を送付】

【出力の形】
次の項目ごとに、見出しと本文案を出してください。
1. 相手の課題（材料にある内容だけで整理）
2. 提案内容（何を、どうやって行うか）
3. 提案の根拠（材料にある実績・事例だけ）
4. 費用感（金額は【材料】にある場合のみ。ない場合は「ここに人が記入」と書く）
5. 次の一歩（相手が取る行動と、こちらが取る行動を分けて）

【条件】
・材料にない数字、社名、事例、効果は書かない。必要なら「【要確認】」と書いて空欄にする
・断定できないことは「〜と考えられます」のように弱めて書く
・各項目は箇条書きで3〜5行以内
・最後に、材料が足りなくて書けなかった項目の一覧を出す
```

この依頼文のポイントは3つあります。1つ目は、材料と出力の形を分けていることです。2つ目は、「材料にない数字は書かない」「ない場合は空欄にする」と明記していることです。3つ目は、最後に「書けなかった項目の一覧」を出させていることで、これがそのまま、自分が埋めるべき宿題リストになります。

出てきた骨組みの「【要確認】」と「ここに人が記入」の部分は、必ず自分で埋めます。うまく指示が通らないときは、[AIへの指示文(プロンプト)の書き方基本ガイド](/prompt-no-kakikata-kihon/)も参考にしてください。

## スライドに落とし込む：イルシル

骨組みができたら、次はスライドへの落とし込みです。白紙のキャンバスにゼロから配置していく作業が、実は一番手が止まりやすいところです。ここで使えるのが、AIスライド作成ツール「イルシル」です。伝えたいテーマや要点を入力すると、スライドの構成とデザインのたたき台を組み立ててくれるタイプのツールで、空白から作る代わりに、たたき台を直していく進め方ができます。

{{aff:irusiru}}

営業資料での使い方としては、先ほどの骨組みのうち、人が確認を終えた部分をテキストとして渡し、スライドの下書きを作らせる形が基本です。自社の実績データを渡す場合は、表やグラフにするのに向く並べ方を提案してもらい、数字自体は自分の手元の資料から入れ直すと安心です。生成されたスライドに、顧客固有の情報や交渉上のポイントを加筆していくところが、営業担当者の仕事になります。

削減できる作業の量は、資料の分量や慣れによって変わります。ツールの機能や料金も変わることがあるため、最新の情報は公式サイトでご確認ください。操作の詳しい流れは[イルシルでAIスライド資料を作る方法](/irusiru-ai-slide-tsukurikata/)で紹介しています。また、イルシル以外も含めてどのツールが合うかを比べたいときは、[AI資料作成ツールの選び方｜作り方のタイプで決める](/shiryou-sakusei-tool-erabikata/)が判断の助けになります。

## 提案書に入れるイメージ画像を用意する：ConoHa AI Canvas

構成とテキストが整っても、表紙や章の区切りに使うイメージ画像が見つからず、素材サイトを探し回って時間が過ぎることがあります。そこで使えるのが、ブラウザで使える画像生成サービス「ConoHa AI Canvas」です。作りたいイメージを文章で指定して、画像を生成できます。

{{aff:conoha-ai-canvas}}

提案書で画像生成が向くのは、あくまで補助的な場面です。

- 表紙や章の区切りに置く、資料のトーンに合わせた雰囲気のイメージ
- サービスの世界観を伝えるための、抽象的なビジュアル
- 既存の素材にはない、コンセプトに沿ったオリジナル画像

逆に、次のものは画像生成に任せないほうが安全です。実在する自社製品や設備の写真、担当者や顧客の顔、他社のロゴ、数字が入ったグラフや図表です。生成画像は細部が不正確になることがあり、文字や数字が入った画像を作らせると誤りが混ざる可能性があります。図表は、スライド側の機能で自分で作るほうが確実です。

画像を頼むときは、「用途(表紙用、横長)」「雰囲気(落ち着いた、青系)」「入れたくないもの(文字、人物の顔)」の3点を書くと、イメージに近づきやすくなります。生成画像のテイストや商用利用時の扱いはサービスにより異なるため、使う前に公式サイトで利用条件を確認してください。

## 実践フローと、提出前の確認手順

ここまでをつなげると、次の流れになります。

1. **骨子を決める**：誰に、何を伝えたいか、結論は何かを自分の頭で整理する
2. **骨組みをAIに作らせる**：上の依頼文で、課題・提案・根拠・費用感・次の一歩を項目で出させる
3. **宿題を埋める**：「【要確認】」の項目に、顧客固有の情報、価格、実績の数字を自分で入れる
4. **スライド化する**：イルシルなどで、確認済みの内容からたたき台を作る
5. **ビジュアルを補う**：ConoHa AI Canvasで表紙や区切りの画像を用意する
6. **提出前に確認する**：下の手順で、相手に出して困る誤りがないかを見る

AIで作った資料の怖さは、見た目が整っているぶん、誤りがあっても気づきにくいことです。提出前には、次の順番で確認します。

1. **数字を全部拾う**：金額、日付、数量、実績の数字を一覧にし、元の資料(見積書、契約書、社内データ)と1つずつ突き合わせる。元がない数字は消す
2. **社名・部署名・人名を検索する**：相手の会社名を検索機能で全ページから探し、表記ゆれや、別の案件の社名が残っていないかを見る。前回の提案書を流用した場合は特に危険
3. **敬称と表記を見る**：「御社」「貴社」、「様」の付け忘れ、担当者名の漢字を確認する
4. **社外秘が混ざっていないか見る**：他社事例の固有名詞、社内の原価や利益率、他の顧客に関する情報、スライドのノート欄やコメントに残ったメモを確認する
5. **約束の表現を読む**：「必ず」「保証」「〜を実現します」など、約束になる表現を、本当に約束してよいか自分で判断する
6. **ファイルの情報を消す**：作成者名、コメント、変更履歴が残っていないかを確認してから送る

なお、社外秘や個人情報を対話型AIやツールに入力してよいかは、会社のルールと各サービスの利用規約によります。入力する前に、社内の方針を確認してください。迷うときは、社名を「A社」のように置き換え、金額や個人名を伏せて入力する方法もあります。

## こんなケースに向く・向かない

向くのは、次のような場面です。

- 提案書のたたき台を、自分で一から組むよりも早く用意したい営業担当者
- デザインに自信がなく、レイアウトの調整に時間がかかってしまう人
- 見た目よりも、課題の整理や提案内容の検討に時間を使いたい人

向かない、あるいは使い方を限ったほうがよいのは、次のような場面です。

- 企業のブランドガイドラインを厳密に守る必要がある資料(AIの出力は、参考程度にとどめるのが無難です)
- 入札や契約書の添付資料など、記載内容に厳密な正確さが求められる書類
- 相手の課題が複雑で、聞き取りがまだ不十分なとき(骨組みを作る前に、先に聞き取りを進めてください)

## まとめ

営業資料・提案書の作成は、内容の検討以上に、構成づくりとビジュアル準備に手間を取られがちな仕事です。依頼文で材料と出力の形を指定して骨組みを作り、イルシルのようなスライド作成ツールでたたき台にし、足りないイメージ画像は画像生成で補う。この流れは、手を止めやすい部分を軽くする選択肢になります。

ただし、顧客の課題の見立て、価格、約束する内容、実績の数字は、人が決める部分です。AIが作ったものは必ず提出前の確認手順を通し、最終的な責任は自分が持つ。この線引きを守れば、AIは頼もしい下書き係になります。
