SNS運用をしていると、「毎日投稿を作るのに時間がかかる」という悩みをよく聞きます。特に小さなお店や個人事業主の場合、接客や仕入れ、制作といった本業をこなしながら投稿も用意することになり、投稿作成が負担になりがちです。

文章を作るAI、画像を作るAI、文字を載せるテンプレート型のデザインツールを順番に使うと、白紙の状態から考える時間を減らしやすくなります。ただし、AIに任せきりにすると、お店の実情と違うことが書かれたり、画像の文字が崩れたりします。この記事では、投稿1本を完成させるまでの流れと、依頼文の実物、画像の用意の仕方、投稿前の確認、AIに任せる範囲と人が決める範囲までを順に紹介します。

## 先に決めておくこと｜お店の情報と伝えたいこと

AIに「いい感じの投稿を作って」と頼むと、どこの店にも当てはまる無難な文章が返ってきます。お店らしい投稿にするには、AIに渡す材料を先にそろえておく必要があります。材料は大きく2種類に分けられます。

1つ目は、毎回変わらないお店の情報です。屋号、扱っている商品、お客さんの層、普段の言葉づかい、よく使う絵文字の有無、ハッシュタグの付け方などです。これは一度メモにまとめておけば、以降の投稿で使い回せます。

2つ目は、その投稿で伝えたいことです。新商品の入荷なのか、営業日の変更なのか、季節のおすすめなのかを一言で書き出します。あわせて、読んだ人にしてほしい行動（来店、予約、保存など）も決めておきます。

ここで意識したいのは、「完璧な文案」を作ろうとしないことです。箇条書きのメモで十分です。たとえば、次のような形です。

- 伝えたいこと：深煎りの新しいコーヒー豆が入荷した
- 読んでほしい人：仕事帰りに立ち寄る常連さん
- 行動：今週中に試飲に来てもらう
- 雰囲気：落ち着いた、押しつけがましくない

そしてもう一つ、「入れたくない表現」も先に書いておくと、後の修正が減ります。たとえば「最高」「日本一」のような言い切り、他店との比較、過剰な絵文字などです。AIは頼まなければ、にぎやかで景気のいい言い回しを足してくることがあります。

## 投稿文の下書きを作る依頼文｜そのまま使える実物

材料がそろったら、文章生成AIに下書きを頼みます。ChatGPTなどの対話型AIなら、次の形で依頼できます。かっこの中を自分のお店の内容に置き換えて使ってください。

```
あなたは（カフェ）のSNS担当です。次の条件でInstagramの投稿文の下書きを3案作ってください。

【お店の情報】
・店名：（○○珈琲）
・お客さん：（近所に住む30〜50代、仕事帰りの常連が中心）
・文体：（です・ます調。やわらかいが、くだけすぎない）

【今回伝えたいこと】
・（深煎りの新しいコーヒー豆が入荷した）
・（今週中なら試飲できる）

【条件】
・本文は（150字前後）
・最後に来店を軽く促す一文を入れる
・書かれていない情報（価格、産地、日付、特典）は勝手に足さない。必要なら（　）で空欄にする

【入れたくない表現】
・「最高」「日本一」などの言い切り
・他店との比較
・絵文字は文末に1つまで
```

この依頼文のポイントは3つあります。第1に、お店の情報と今回の内容を分けて渡していることです。お店の情報は固定し、今回の内容だけを差し替えれば、同じ依頼文を何度も使えます。第2に、「書かれていない情報は足さない」と明記していることです。AIは文章を自然にするために、もっともらしい価格や産地を補うことがあるため、空欄にさせておくと確認の手間が減ります。第3に、3案を出させていることです。1案だけだと、良し悪しの比較ができません。

返ってきた案は、そのまま使わずに読み比べます。「この言い方はうちの店らしくない」と感じた箇所は、次のように具体的に直しを依頼します。

```
2案目をもとに、次の点を直してください。
・1文目を、挨拶ではなく豆の話から始める
・「ぜひ」「ご自由に」の言い回しをやめ、「今週は試飲できます」と事実だけを書く
・全体を少し短くする
```

「もっと良くして」ではなく、直す箇所と方向を指定するほうが、意図に近い文章が返ってきやすくなります。文がまとまったら、最後は自分の声に読み替えて仕上げます。声に出して読んで違和感のある語尾や言い回しは、人の手で直すのが確実です。

## 画像の用意｜文字は描かせず、テイストをそろえる

投稿文の方向が決まったら、画像を用意します。画像生成AIなら、文章で指示するだけで写真風やイラスト風の画像を作れます。ConoHa AI Canvasのようなサービスもあり、使い方や料金は変わることがあるため、最新の内容は公式サイトで確認してください。

画像の指示文は、「何が写っているか」「どんな雰囲気か」「どう切り取るか」の3つを書くと、意図に近づきやすくなります。たとえば次のような形です。

```
白い木のテーブルに置かれたコーヒー豆の入ったガラス瓶。
窓からのやわらかい自然光、落ち着いた温かい色合い。
上から少し斜めに見下ろす構図。画像の中に文字やロゴは入れない。
```

ここで重要なのが、最後の一文です。画像生成AIは文字を正確に描くのが苦手で、誤字や崩れた文字が入りやすいため、文字は画像に描かせず、後からデザインツールで載せるのが基本です。この考え方は、[AIで文字入りバナーを作る方法｜文字は後から載せる](/ai-gazou-moji-ireru/)で詳しく説明しています。文字を載せる余白が必要なら、「画像の上側に余白を多めに」と指示に入れておくと、後の作業が楽になります。

もう一つは、複数の投稿でテイストをそろえることです。投稿ごとに写真風、水彩風、イラスト風と変わると、アカウントの印象がばらつきます。次の3点を固定すると、そろえやすくなります。

- 色合い：暖色寄り、くすんだ淡い色など、使う色味を言葉で決めておく
- 光と構図：自然光、上から見下ろす、余白を多めにとる、など
- 画風：写真風か、イラスト風か。途中で混ぜない

この3点を指示文の末尾に共通の「決まり文句」として入れておけば、毎回書き直す必要がありません。詳しい手順は[AI画像のテイストをそろえる方法｜複数枚で統一感を出す](/ai-gazou-tone-soroeru/)を参照してください。

うまくいかなかったときの戻し方も決めておきます。思った絵にならないときは、いきなり指示文を長くせず、1つずつ条件を変えて試します。たとえば雰囲気の言葉だけを変える、構図だけを変える、といった具合です。何が効いたのかが分かるので、次回以降の指示文に活かせます。費用をかけずに試したい場合は、[AI画像生成ツールの始め方｜無料の範囲と月額の違い](/muryou-ai-gazou-seisei/)も参考になります。

画像の生成には、ConoHa AI Canvasのように、ブラウザから使える画像生成サービスを使う方法もあります。プランや使い方は変わることがあるので、公式サイトで確認してから試してください。

## 体裁を整える｜テンプレート型ツールで文字を載せる

生成した画像に、店名や日付、一言のコピーを載せる作業には、テンプレート型のデザインツールが向いています。MiriCanvasやCanvaのように、あらかじめ用意されたレイアウトに画像と文字を当てはめていくタイプです。デザインの経験がなくても、読みやすい字体や配置が最初から整っているので、仕上がりが安定しやすくなります。

進め方は次のとおりです。まず、投稿先に合ったサイズ（正方形、縦長など）のテンプレートを選びます。サイズの種類はツールによって異なるため、使うツールで確認してください。次に、生成した画像を背景に配置します。最後に、文字を打ち込みます。このとき、文字は短くまとめ、背景と文字の色の差をはっきりさせます。

一度気に入ったレイアウトができたら、複製して保存しておきます。次回からは画像と文字を差し替えるだけで済み、毎回の仕上がりも一定になります。AIが作った画像に不自然な部分があっても、トリミングや余白で目立たなくできる場合があります。

文字量の目安は、「画像を見てすぐに何の投稿か分かる」程度です。詳しい説明は投稿文に任せ、画像には店名と要点だけを載せます。

## 投稿前の確認｜事実・写り込み・規約

AIが作った文章や画像は、見た目が整っているぶん、間違いに気づきにくいという面があります。投稿ボタンを押す前に、次の表の順で確認してください。

| 確認すること | 見る場所 | 見つけたときの直し方 |
|---|---|---|
| 事実、価格、日付、営業時間 | 投稿文と画像の文字 | メモや店の資料と照らし合わせ、違えば人の手で直す |
| 他人の写真や作品が写り込んでいないか | 画像の背景、小物、人物 | 該当部分を作り直すか、使わない |
| 既存のロゴや有名な作品に似すぎていないか | 画像全体 | 似ていると感じたら指示文を変えて作り直す |
| 誤字、崩れた文字 | 画像内の文字 | 後から載せた文字はテキストを直す |
| AIで作った画像であることの扱い | 投稿の注記、各サービスの方針 | 利用するAIサービスの規約と、SNS側の方針を確認する |

特に注意したいのは、価格と日付です。AIは頼んでいない数字を、もっともらしく書くことがあります。依頼文で「書かれていない情報は足さない」と指定していても、最終確認は人が行います。

画像では、背景や小物にも目を向けます。他人の写真、他店の看板、人の顔、既存のキャラクターに似たものが入り込んでいないかを見ます。迷ったときは、使わないほうが安全です。

AIで作った画像であることをどう扱うかは、利用するAIサービスの規約や、投稿するSNSの方針によって異なります。注記が必要か、商用利用ができるかは、サービスごとに公式の案内で確認してください。規約は変わることがあるため、継続的に使うツールは、折に触れて見直すと安心です。お客さんが「実際の商品写真」と受け取りかねない使い方は避けます。商品そのものを見せる投稿には、実際に撮った写真を使うのが無難です。著作権の考え方は[AIと著作権の基本|生成画像や文章は誰のもの?](/ai-to-chosakuken-kihon/)にまとめています。

## AIに任せることと人が決めること

ここまでの作業を、AIに任せる部分と人が決める部分に分けると、次のようになります。

| 作業 | AIに任せやすい | 人が決める |
|---|---|---|
| 投稿文 | 複数の言い回しの案出し、短縮、言い換え | 伝える内容、価格や日付などの事実、最終的な言葉選び |
| 画像 | 背景や雰囲気のイメージ作り、バリエーション出し | 使う画像の選択、写り込みの確認、商品そのものの写真 |
| 文字入れ | レイアウトの候補を試す | 載せる文言、店名や連絡先の正確さ |
| 投稿計画 | 投稿の種類ごとの下書き | いつ、何を、どの頻度で出すか |
| 公開前の判断 | 誤字の指摘など、見落とし防止の補助 | 公開してよいかの最終判断 |

「どれだけ時間が短くなるか」は、お店や慣れによって変わるため、一概には言えません。1本目は慣れずに時間がかかっても、依頼文と画像の指示文、テンプレートが手元にたまってくると、準備にかける手間は変わってきます。何本か作って、自分のお店でどの作業に時間がかかるのかを測ってみてください。

続けやすくする工夫も3つあります。1つ目は、依頼文のひな形を投稿の種類ごと（商品紹介、営業案内、豆知識など）に保存しておくことです。2つ目は、デザインのテンプレートを1つか2つに絞ることです。3つ目は、複数の投稿をまとめて企画しておくことです。毎日ゼロから考えるより、1週間分の材料をまとめて整理するほうが、AIへの依頼も効率的です。

## まとめ

SNS投稿の作成は、次の流れで進められます。

1. お店の情報と、今回伝えたいこと、入れたくない表現を整理する
2. 条件を書いた依頼文で、文章の下書きを複数案作る
3. 文字を入れない指示で画像を作り、テイストをそろえる
4. テンプレート型ツールで文字を載せて整える
5. 事実、価格、日付、写り込み、規約を確認してから投稿する

AIは、案を出し、手間を減らしてくれる助け手です。何を伝えるか、どんな言葉でお店を表すか、投稿してよいかどうかは、人が決めることです。まずは1本、依頼文の実物を自分のお店の内容に置き換えて試してみてください。
