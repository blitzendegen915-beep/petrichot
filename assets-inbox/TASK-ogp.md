# 依頼: OGP画像の作り直し

SNSでURLが共有されたときに表示される画像です。X運用を始めたので、ここの見栄えが流入に直結します。

## 作るもの

| 項目 | 指定 |
|---|---|
| ファイル名 | `ogp.png` |
| 寸法 | **1200 × 630 px**（厳守。Xのカード比率） |
| 形式 | PNG |
| 容量 | **300KB以下**（現行は108KB。これを大きく超えないこと） |

差し替え先は `affiliate/static/ogp.png` です。置き場所は `assets-inbox/` で、`manifest.json` への記載も必要です（`assets-inbox/README.md` 参照）。

## 内容

- サイト名: **AIツールの透視図**
- サイトURL: petrichot.com
- 日本語のサイトです。**日本語フォントが崩れていないこと**を必ず目視で確認してください（豆腐・文字化け・不自然な字形がないか）

## デザインの条件

- **文字を小さくしない。** タイムラインでは横240px程度に縮んで表示されます。その大きさで読めるかを基準にしてください。サイト名は画像の高さの1/6以上を目安に
- 既存サイトの配色に合わせる
  - アクセント: `#1a5ce5`（青）
  - 濃い青: `#10287d`
  - 背景: `#ffffff`
  - 文字: `#111318`
  - 淡い青: `#e9f0ff`
- 端から40px以上は余白を取る（環境によって端が切れます）
- 情報を詰め込まない。サイト名＋短い説明で十分です

## やってはいけないこと

- **実在する企業のロゴを入れない**（OpenAI、Google、Anthropic等）— 商標の問題になります
- **人物の写真・顔を入れない** — 肖像権の判断が別途必要です
- **他所から拾った画像素材を使わない** — 出所が分からないものは載せられません。自分で生成・描画したものだけにしてください
- 効果や実績を主張する文言を入れない（「No.1」「最速」など）

## 提出時

`assets-inbox/manifest.json` に必ず記載してください。

```json
{
  "assets": [
    {
      "file": "ogp.png",
      "purpose": "サイト全体のOGP画像（差し替え）",
      "source": "generated",
      "license": "（使用したツール名と、素材を取り込んでいないことの明記）",
      "alt": "AIツールの透視図のロゴとサイト名"
    }
  ]
}
```

置いたら、こちらで `node affiliate/check-assets.mjs` を通してから反映します。
