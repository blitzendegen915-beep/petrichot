プログラミングスクールを検討するとき、多くのスクールは、体験や個別の相談の機会を用意しています。ただし、その有無や内容、費用の扱いはスクールによって異なります。利用できるかどうかは、各スクールの公式サイトで確認してください。

体験や相談の場は、資料だけでは分からない部分を確かめる貴重な機会です。ところが、何を聞けばよいか分からないまま参加すると、説明を受けて終わってしまいます。この記事では、体験・相談の前に準備すること、当日に聞くこと、判断の仕方を整理します。スクール選びの基準そのものは[プログラミングスクールの選び方｜失敗しない5つの基準](/learning/programming-school-erabikata/)で扱っているため、ここでは「面談の場での確かめ方」に絞ります。

## 体験・相談の位置づけを理解する

体験や相談の場は、スクールにとっては自社の説明をする場であり、受講者にとっては相性や条件を確かめる場です。両者の目的が違うことを理解しておくと、冷静に参加できます。

スクール側は、サービスの特徴を伝えようとします。当然、良い面を中心に話すでしょう。これは悪いことではなく、説明の場の性質です。そのため、受講者の側から、知りたいことを積極的に質問する姿勢が重要になります。

参加するだけで入会を決める必要はありません。その場で契約を急かされた場合でも、持ち帰って検討して構いません。その場の雰囲気に流されて決めないために、「今日は情報を集める日」と決めて参加するとよいでしょう。

また、体験や相談を利用するかどうかも、状況によって判断できます。独学と比べてスクールが自分に合うかを迷う段階であれば、[独学とスクールどっちが向いてる?正直な比較](/learning/dokugaku-vs-school-hikaku/)で考え方を整理してから参加すると、質問が具体的になります。

オンラインで学べるプログラミングスクールの一つに、TechAcademyがあります。コースの内容、受講の形式、料金、体験や相談の有無などは変わる可能性があるため、公式サイトで確認してください。

どのスクールを検討する場合でも、同じ質問を複数のスクールに投げかけ、回答を並べて比べるのが基本です。比較の土台になるよう、質問は共通の形にしておきます。

## 参加する前に準備すること

体験や相談の効果は、事前の準備で大きく変わります。次の項目を、メモにまとめておきましょう。

| 準備すること | 具体的な内容 |
|--------------|--------------|
| 学ぶ目的 | 転職、副業、現職での活用、趣味など |
| 現在の水準 | 経験の有無、これまで学んだこと |
| 使える時間 | 平日・休日の学習に割ける時間帯 |
| 費用の考え方 | 自己負担できる範囲、分割の希望など |
| 学び方の希望 | 通学かオンラインか、質問のしやすさ |
| 不安なこと | 続けられるか、挫折しないかなど |

目的が定まっていないと、スクールの説明を受けても、自分に合うか判断できません。目的が曖昧なら、先にゴールのイメージを描いておくことをすすめます。たとえばAIやITの分野に進みたい場合は、[未経験からAIスキルを身につけるロードマップ](/learning/ai-skill-roadmap-2026/)のように、全体の道筋を把握してから面談に臨むと、質問の質が上がります。

さらに、スクールの公式サイトを事前に読んでおくことも重要です。料金、コース内容、受講期間、サポートの範囲など、公式サイトに書かれている情報は、当日に質問する必要はありません。サイトを読んでも分からなかった点や、サイトの記載があいまいな点を、当日の質問に回します。

参加前に、質問を書き出しておきましょう。当日は緊張したり、話に引き込まれたりして、聞きたいことを忘れがちです。メモを手元に置き、一つずつ確認していくと漏れを防げます。録音やメモの可否については、事前に確認しておくと安心です。

## 学び方とサポートについて聞くこと

最初に確認したいのは、日々の学び方とサポートの内容です。ここは、続けられるかどうかに直結します。質問の例を、コードブロックにまとめます。

```
【学び方】
・教材は、どのような形式で提供されますか（動画、テキスト、課題など）
・一日の学習の流れを、具体例で教えてください
・自分のペースで進められますか。決まった日程はありますか
・受講期間が終わったあとに、教材を見返せますか

【サポート】
・質問は、どの手段で、どの時間帯に受け付けていますか
・質問への回答には、どのくらい時間がかかるのが通常ですか
・質問できる相手は、どのような立場の方ですか
・課題やコードの確認（レビュー）はありますか
・学習の進み具合を相談できる機会はありますか
```

特に、質問の対応については、具体的に聞いてください。「手厚いサポート」といった抽象的な表現では、実際の内容が分かりません。手段、時間帯、回答までの目安、相手の立場を確認すると、実態が見えてきます。

また、つまずいたときにどうなるかを聞いておきます。たとえば、課題が進まないとき、スクール側から連絡が来るのか、自分から相談する必要があるのか。続けられるかどうかに関わる、大切な点です。

回答があいまいな場合は、「たとえば、どのような場合ですか」と重ねて聞いてみましょう。実例を挙げて答えられるかどうかは、運営の実態を知る手がかりになります。ただし、回答の内容は担当者の説明にすぎません。重要な点は、後から書面や公式サイトで確認できるかも尋ねておきます。

## 費用・契約・解約について聞くこと

次に、お金と契約の条件を確認します。費用の話は聞きづらいと感じる方もいますが、納得して決めるために欠かせません。ここでも、具体的な金額はスクールごとに異なるため、公式の情報と面談での説明の両方で確認します。

| 確認すること | 質問の例 |
|--------------|----------|
| 費用の内訳 | 支払う費用に、何が含まれていますか。別途かかる費用はありますか |
| 支払い方法 | 一括以外の支払い方法はありますか。変更はできますか |
| 契約期間 | 期間の途中で、延長や短縮はできますか |
| 中途解約 | 途中でやめる場合の手続きと、返金の扱いを教えてください |
| 休会 | 仕事や体調の都合で止めたいとき、どうなりますか |
| 契約書 | 契約の条件が書かれた書面は、事前に確認できますか |

とくに重要なのは、解約と返金の扱いです。学習を始めてから、仕事が忙しくなったり、内容が合わなかったりする可能性はあります。その場合の条件を、契約の前に確認しておきます。口頭の説明だけでなく、契約書や規約に書かれていることを確かめてください。

契約に関するトラブルを避けるため、その場で署名や支払いを求められても、慌てて決めないようにしましょう。契約書を持ち帰って読み、不明点を質問してから判断して問題ありません。

公的な支援が使えないか知りたい場合は、スクールに尋ねるだけでなく、運営している機関の公式情報も確認します。厚生労働省の公式サイト（https://www.mhlw.go.jp/）で案内を探せます。対象かどうかの判断は、制度を運営する機関の情報に基づいて行ってください。

## 成果・実績・サポート後について聞くこと

スクールによっては、卒業後の進路や、受講生の成果について説明します。このような説明を受けたときは、内容を鵜呑みにせず、根拠や条件を確認することが大切です。

確認したい質問を、次のように整理します。

- その説明は、どのような条件の受講生が対象ですか
- 数値や事例は、いつ時点の情報ですか
- 成果は、受講生の努力や条件によって変わりますか
- 転職や案件の紹介を行う場合、その内容と条件はどうなっていますか
- 紹介を受けるための条件はありますか

実績の説明は、見せ方によって印象が大きく変わります。成功した事例だけが強調されていないか、全体の中でどの程度のものなのか、冷静に見てください。保証する形の表現があった場合は、その範囲と条件を、書面で確認しましょう。

また、修了後のサポートについても聞いておきます。教材を見返せる期間、卒業後の質問対応、コミュニティの有無など、学習が終わったあとの関わり方は、スクールごとに異なります。

自分が目指す進路と、スクールの説明が合っているかも確かめましょう。たとえば転職を考えているなら、必要な準備や現実的な道筋を、先に確認しておくと比較しやすくなります。転職の観点は[未経験からのIT転職|現実的な道筋と必要な準備を徹底解説](/learning/mikeiken-it-tenshoku-genjitsu/)にまとめています。

## 参加後の振り返りと、断るときの考え方

体験や相談が終わったら、記憶が新しいうちに振り返ります。次の表のように、共通の項目で評価を残すと、複数のスクールを比べやすくなります。

| 観点 | 振り返りの問い |
|------|----------------|
| 説明の分かりやすさ | 質問に具体的に答えてくれたか |
| 相性 | 担当者との会話は話しやすかったか |
| 学び方 | 自分の生活リズムで続けられそうか |
| サポート | つまずいたときの支えがイメージできたか |
| 費用と条件 | 契約や解約の条件に納得できたか |
| 引っかかった点 | 不安や疑問が残った点は何か |

気になる点が残る場合は、再度問い合わせて確認します。回答を濁されたり、急いで契約を迫られたりした場合は、慎重に判断してください。

断ることに気が引ける方もいますが、断ることは失礼ではありません。複数の候補を比べるのは当たり前のことです。断るときは、簡潔に伝えれば十分です。

```
先日はご説明をありがとうございました。
検討した結果、今回は見送ることにしました。
お時間をいただき、ありがとうございました。
```

理由を細かく説明する義務はありません。その後の連絡が続く場合は、連絡不要の旨を伝えることもできます。

最終的な判断は、スクールが良いか悪いかではなく、「自分の目的と条件に合うか」で行います。独学で進めるという結論になるのも、立派な選択です。

## まとめ

体験や相談は、資料では分からない部分を確かめる機会です。有無や内容はスクールごとに異なるため、公式サイトで確認してください。参加前に目的や条件を整理し、公式サイトで分かる情報は事前に読んでおきます。

当日は、学び方とサポートの具体的な中身、費用と契約と解約の条件、成果の説明の根拠を確認します。回答はメモに残し、重要な点は書面でも確かめます。その場で決めず、複数のスクールに共通の質問をして比べると、納得して選べます。
