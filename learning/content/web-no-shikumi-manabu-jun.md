Webの学習は、HTML、CSS、JavaScriptの三つから始めるのが一般的です。ただ、「どれから学べばよいか」「並行してよいか」と迷うかもしれません。順番を間違えても取り返しはつきますが、役割の違いを知っておくと遠回りを減らせます。

この記事では、Webサイトが表示される仕組みを簡単に押さえたうえで、三つの技術を学ぶ順番と、各段階で確認したいことを整理します。Pythonなど別の言語から入りたい人は、[Python学習の始め方｜最初の3ヶ月でやること](/learning/python-gakushuu-hajimekata/)も選択肢になります。

## Webサイトが表示される流れをつかむ

学習の前に、Webサイトが画面に出るまでの流れを大まかに知っておくと、三つの技術の位置づけが分かりやすくなります。

利用者がブラウザでアドレスを入力すると、ブラウザはそのアドレスの先にあるコンピューター（サーバー）に、ページを見せてほしいという依頼を送ります。サーバーは、HTMLという文書や、見た目を決めるCSS、動きを加えるJavaScriptのファイルを返します。ブラウザは受け取ったものを組み立てて、画面に表示します。

つまり、学ぶ三つの技術は、次のように役割が分かれています。

| 技術 | 役割 | たとえ |
|-----|------|------|
| HTML | 文書の構造と内容を表す | 建物の骨組みと部屋 |
| CSS | 見た目を整える | 壁の色や家具の配置 |
| JavaScript | 動きや反応を加える | 照明のスイッチや自動ドア |

この例えは一つの目安です。実際には、HTMLだけでも文書として表示でき、CSSがなくても読めます。JavaScriptがなくても、静的なページは成立します。それぞれが独立した役割を持ちつつ、組み合わせて使われます。

この全体像を持っておくと、「いま学んでいるのはどの部分か」が分かります。たとえば、文字の色を変えたいときにHTMLの書き方を調べても答えは見つかりにくく、CSSを調べると見つかります。迷ったときに探す場所の見当がつくことが、仕組みを先に理解する利点です。

## 最初に学ぶのはHTML｜文書の構造を書く

最初の一歩はHTMLです。理由は、他の二つが、HTMLで作った構造の上に成り立っているからです。構造がなければ、色を付ける対象も、動かす対象もありません。

HTMLの学習では、次のことを順に確認します。

- 見出し、段落、リストなど、文書の基本的な部品の書き方
- 画像やリンクの埋め込み方
- 表や入力フォームの作り方
- 要素の入れ子（親子関係）の考え方
- 意味に合った部品を選ぶこと

特に最後の点は、見落とされがちです。見た目が同じに見えても、文書として何を表しているかを正しく書くと、読み上げ機能を使う人や検索の仕組みにも伝わりやすくなります。見た目の調整はCSSに任せ、HTMLは「これは見出し」「これはリスト」と意味を示す、という分担を意識しましょう。

学習の進め方は、手本を見て写し、少し変えて試す繰り返しが効果的です。たとえば、自己紹介のページを作ってみます。名前、好きなもの、リンクを並べるだけで、HTMLの基本部品を一通り使えます。ブラウザで開いて表示を確認し、思ったとおりでなければ、どこが違うのかを見直します。

つまずきやすい点は、閉じ忘れや入れ子の間違いです。文書の一部が崩れて表示されたら、タグが正しく閉じているかを確認しましょう。エディターの色分け機能が、間違いに気づく助けになります。

動画で学べるサービスとしては、ドットインストールなどがあります。扱うレッスンや料金は更新されるため、公式サイトでご確認ください。

## 次に学ぶのはCSS｜見た目と配置を整える

HTMLで文書が書けるようになったら、次はCSSです。CSSは、文字の大きさや色、余白、並べ方などを指定する言語です。

CSSの学習で最初に押さえたいのは、「どの要素に、どの見た目を適用するか」を指定する仕組みです。これをセレクターと呼びます。たとえば、すべての見出しの色を変える、特定のボタンだけ背景を変える、といった指定ができます。この考え方に慣れると、後の学習が楽になります。

次に、箱の考え方を学びます。画面上の各要素は、内容、内側の余白、枠線、外側の余白という層を持つ箱として扱われます。余白がうまく調整できないときは、この箱のどの層を調整しているのかを確認すると、原因が見つかります。

配置の学習も重要です。要素を横に並べる、中央に寄せる、画面の幅に応じて並びを変えるといった技術は、実際のページ作りで頻繁に使います。画面の幅が違う端末でも見やすく表示するための考え方は、現在のWebでは基本的な内容です。

CSSでは、思いどおりに動かないときの原因探しです。その場合は、次の手順を試してください。

1. 指定した対象が、意図した要素になっているか確認する
2. 同じ要素への別の指定が、上書きしていないか確認する
3. 書き間違い（綴り、記号）がないか確認する
4. ブラウザに備わっている開発者向けの機能で、適用された指定を見る

最後の方法は、操作の名前や画面が更新されることがあるため、各ブラウザの公式の説明で確認してください。ここまで進むと、見た目の整ったページが作れるようになります。

## 最後にJavaScript｜動きと反応を加える

JavaScriptは、三つのうちで最も学ぶことが多く、プログラミングの考え方が必要になる部分です。そのため、HTMLとCSSで画面を作る感覚を得てから取り組むのが、現実的な順序です。

JavaScriptでできることは、利用者の操作に反応して画面を変えることです。ボタンを押すと文字が変わる、入力内容を確認する、表示を切り替えるといった動きを作れます。

学ぶ順序は、まず基本的な文法から始めます。

- 変数とデータの種類
- 条件分岐（もし〜ならば）
- 繰り返し処理
- 関数（処理のまとまり）
- 画面の要素を取得して書き換える方法
- 利用者の操作（クリックなど）に反応する方法

最後の二つがWebならではの内容です。それまでの文法は、他の言語でも通用する考え方です。ここまで進めば、画面と処理をつなぐ感覚が得られます。

JavaScriptの学習は、小さな課題から始めましょう。最初は、ボタンを押したら文字が変わるだけで構いません。そこから、入力した文字を表示する、リストに項目を追加する、と少しずつ複雑にします。

エラーが出たときは、焦らず、エラーメッセージの内容を読みます。ブラウザの開発者向けの機能に、エラー内容が表示されます。メッセージには、どのファイルの何行目で問題が起きたかが書かれていることが多いので、まず自分で読み解く練習をしましょう。

## 三つを組み合わせて小さく作り、順番に迷ったら見直す

個別に学んだら、組み合わせて一つのページを作ります。ここまでの理解を確認するうえで、実際に動くものを作る経験が最も役立ちます。

題材は、身近なものから選びましょう。

| 題材 | 使う技術 | 確認できること |
|-----|---------|-------------|
| 自己紹介ページ | HTML、CSS | 構造と見た目の分担 |
| 持ち物チェックリスト | HTML、CSS、JavaScript | 画面の操作と変化 |
| 簡単な計算ツール | HTML、JavaScript | 入力と結果の表示 |
| 画像を切り替えるページ | 三つすべて | 組み合わせ全体 |

作り方のコツは、最初から完成を目指さず、一段階ずつ動作を確かめることです。たとえば、チェックリストなら、まず項目を表示するだけのページを作ります。次に見た目を整え、最後にチェックを入れたときの動きを加えます。

作ったものは、記録に残しておきましょう。何を作り、どこで悩み、どう解決したかを書いておくと、学習の振り返りになります。後で作品として整理する際の材料にもなります。

学習の進め方や時間の確保が不安なときは、[学習が続かないのは意志が弱いからじゃない｜続く仕組みの作り方](/learning/gakushuu-tsuzuku-shikumi/)が助けになります。

順番に迷ったときの考え方も、ここで整理します。最後に、順番に迷ったときの考え方を示します。ここまでの順序は一般的な例であり、この順でなければならないわけではありません。

たとえば、動きのあるものを早く作りたいなら、HTMLとCSSの基本を最低限学んだ段階でJavaScriptに触れても構いません。見た目に興味があるなら、CSSを丁寧に掘り下げる期間を長く取るのも一つの方法です。大切なのは、学んだことが画面で確認できる状態を保つことです。

迷ったときは、次の問いで整理してください。

- いま作りたいものは何か
- そのために足りないのは、構造、見た目、動きのどれか
- 足りない部分を、小さな課題で確認できるか

学習が停滞したときは、一つ前の段階に戻って簡単なものを作り直すと、感覚が戻ります。進むことばかり考えず、戻る選択肢も持っておきましょう。

同様の入門的な学習サービスには、Progateのようにブラウザ上で学べるものもあります。形式やコースの内容は変わることがあるため、公式サイトで確認してください。

## まとめ

Webの学習は、仕組みの全体像を知り、HTML、CSS、JavaScriptの順に進めるのが一般的な道筋です。要点を整理します。

- HTMLで文書の構造を書き、意味に合った部品を選ぶ
- CSSで見た目と配置を整え、思いどおりにならないときは原因を順に切り分ける
- JavaScriptで画面に動きと反応を加える
- 学んだら小さなページを作り、三つの組み合わせを確かめる
- 順番に迷ったら、作りたいものから足りない部分を考える

順番は絶対ではありません。自分が作りたいものに合わせて調整しながら、動くものを確かめる習慣を保つことが、学習を前に進めます。止まったときは、一つ前の段階に戻って簡単なものを作り直し、感覚を取り戻してください。

Webの技術は更新されていくため、書き方や推奨される方法が変わることもあります。学ぶ際は、教材の公開時期を確認し、迷ったら公式の説明に当たる習慣をつけておくと安心です。基本の考え方である構造、見た目、動きの分担は、道具が変わっても役立ちます。
